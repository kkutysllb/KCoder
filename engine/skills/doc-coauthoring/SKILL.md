# Doc Co-authoring

A structured workflow for writing documentation together with the user.

## Phases

1. **Context transfer** — interview the user: purpose, audience, key decisions, constraints, open questions. Capture raw context before writing.
2. **Outline agreement** — propose a section skeleton; get explicit sign-off on structure before drafting prose.
3. **Section drafting** — write one section at a time; keep each pass focused.
4. **Iteration** — refine via targeted feedback rounds (clarity → completeness → tone), never rewriting everything each pass.
5. **Reader verification** — re-read as the target audience; check the doc answers their likely questions.

## Rules

- The user owns the decisions; you own structure and clarity.
- Surface gaps explicitly ("Section 3 needs a decision on X") instead of inventing content.
- Prefer concrete examples over abstract descriptions.
