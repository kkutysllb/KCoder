Consistent theming for any artifact: slides, docs, reports, landing pages.

## Theme Anatomy (when generating)

- Palette: bg, surface, text, muted, accent, accent-2 (verify contrast ≥ 4.5:1)
- Type: display + body pairing, modular scale (1.25–1.333)
- Spacing unit + radius + shadow tokens

## Rules

- Apply EVERY token consistently; no one-off colors.
- Match theme energy to content (don't theme a funeral report in Sunset).
