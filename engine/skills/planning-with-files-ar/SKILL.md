# تخطيط المهام بالملفات

نظام تخطيط بنمط Manus للمهام المعقدة.

## الملفات الثلاثة

- **task_plan.md** — تقسيم العمل: مراحل + عناصر قابلة للتحقق
- **findings.md** — نتائج البحث والقرارات والقيود
- **progress.md** — الحالة المباشرة: مكتمل / قيد التنفيذ / متعثر

## سير العمل

1. إنشاء الملفات الثلاثة عند بدء المهمة.
2. تقسيم العمل إلى مراحل ثم عناصر قابلة للتحقق.
3. تحديد العناصر فور اكتمالها وتسجيل النتائج فور اكتشافها.
4. تحديث progress.md عند كل معلم.
5. بعد /clear أو في جلسة جديدة: قراءة الملفات الثلاثة أولاً.

## متى يُستخدم

المشاريع متعددة الخطوات ومهام البحث وأي عمل يتطلب أكثر من 5 استدعاءات أدوات.
