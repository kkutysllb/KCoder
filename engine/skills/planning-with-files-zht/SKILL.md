# 檔案規劃系統

基於 Manus 風格的檔案規劃，用於組織和追蹤複雜任務。

## 三個檔案

- **task_plan.md** — 工作分解：階段 + 可勾選項，唯一進度事實來源
- **findings.md** — 調研結果、決策與約束（附來源）
- **progress.md** — 即時狀態：已完成 / 進行中 / 受阻

## 流程

1. 任務開始時建立三個檔案並初始化結構。
2. 將工作分解為階段 → 可驗證的檢查項。
3. 完成即勾選；發現即記錄到 findings.md。
4. 每個里程碑刷新 progress.md。
5. /clear 或新會話開始時：先讀三個檔案恢復上下文，再行動。

## 適用場景

多步驟專案、研究任務、需要超過 5 次工具呼叫的工作。
