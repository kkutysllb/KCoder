# 文件规划系统

基于 Manus 风格的文件规划，用于组织和跟踪复杂任务。

## 三个文件

- **task_plan.md** — 工作分解：阶段 + 可勾选项，唯一进度事实来源
- **findings.md** — 调研结果、决策与约束（附来源）
- **progress.md** — 实时状态：已完成 / 进行中 / 受阻

## 流程

1. 任务开始时创建三个文件并初始化结构。
2. 将工作分解为阶段 → 可验证的检查项。
3. 完成即勾选；发现即记录到 findings.md。
4. 每个里程碑刷新 progress.md。
5. /clear 或新会话开始时：先读三个文件恢复上下文，再行动。

## 适用场景

多步骤项目、研究任务、需要超过 5 次工具调用的工作。
