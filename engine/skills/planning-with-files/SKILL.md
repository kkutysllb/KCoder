# Planning with Files

File-based planning system for organizing and tracking complex tasks.

## Files

| File | Purpose |
|---|---|
| task_plan.md | Work breakdown: phases + checkable items |
| findings.md | Research results, decisions, constraints |
| progress.md | Live status: done / in-flight / blocked |

## Process

1. Create the three files at task start.
2. Decompose into phases → items; keep items verifiable.
3. Check off items as they complete; append findings immediately.
4. Refresh progress.md at every milestone.
5. After /clear or in a new session: read all three files before acting.

## Triggers

- 任务规划、项目计划、制定计划、分解任务、多步骤规划、进度跟踪
- Task planning, project planning, work breakdown, progress tracking
