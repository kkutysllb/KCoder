# Canvas Design

Create original static visual pieces rendered to PNG/PDF.

## Design Philosophy

- **Concept first** — one clear idea per piece; every element serves it.
- **Structure** — establish a grid and margins before placing anything.
- **Hierarchy** — exactly one dominant focal point; scale everything else beneath it.
- **Restraint** — limited palette (2–4 colors), at most two typefaces.

## Workflow

1. Clarify purpose, audience, dimensions, and content with the user.
2. Sketch the concept in words: focal point, supporting elements, negative space.
3. Implement with code (p5.js / SVG / canvas) or a layout engine; render at print-quality resolution (≥300 DPI equivalent).
4. Export PNG (screen) and/or PDF (print) into the workspace.
5. Present the result and iterate on one aspect at a time.

## Rules

- Original compositions only — never trace or replicate existing artists' work.
- Text in the piece must be legible at final size.
