# Internal Communications

Write internal communications that respect the reader's time.

## Formats

- **Status report** — accomplishments / next steps / blockers; lead with the headline.
- **Leadership update** — one paragraph bottom line up front, then supporting detail; explicit asks.
- **Incident report** — timeline, impact, root cause, remediation, action items with owners.
- **FAQ** — questions phrased as readers would ask them; direct answers first.
- **Newsletter / project update** — scannable sections, one owner per item.

## Principles

1. **BLUF** — bottom line up front; details below.
2. **Explicit asks** — every request states owner and deadline.
3. **Scannable** — headers, bullets, bold key dates/numbers; no walls of text.
4. **Honest signal** — flag risks early with severity; never bury bad news.
