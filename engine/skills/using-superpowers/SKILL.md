# Using Superpowers

Skills are specialized capabilities — always check for one before acting.

## The Rule

Before responding to ANY task (even a clarifying question), scan the skill catalog:
1. Does a skill match this task's type or trigger description?
2. If yes — load and follow it. Skills override generic instincts.
3. If multiple match — apply the most specific one; combine only when complementary.

## Why

- Skills encode verified best practices; improvising ignores them.
- Trigger descriptions exist precisely to catch "this seems simple" cases.

## Anti-patterns

- ❌ Answering directly when a matching skill exists
- ❌ Mentioning a skill without actually applying it
- ❌ Applying a skill that only loosely matches (worse than none)
