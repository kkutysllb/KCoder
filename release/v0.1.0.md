# KCoder v0.1.0

> 发布日期：2026-08-17 · 上游基线：deepseek-harness 0.1.0-rc.5 (47f9438)

## 新特性

- KCoder 桌面端首个正式版本：以 DSH-Desktop v0.1.4 为基线重建，引擎从 QiLin 迁移到 DeepSeek Harness
- 上游基线钉版机制：固定 deepseek-harness rc.5，杜绝 CI 浮动克隆混入未验证上游代码
- 产品隔离与品牌化：KCoder logo/slogan/文案、独立数据目录 ~/.kcoder、打包链 kcoder-runtime 开箱即用（内置上游运行时，安装后无需克隆/构建上游）
- 内置技能体系：73 个技能全部随包加载
- macOS 图标圆角蒙版（squircle 规范，Dock 标准圆角）

## 修复

- 复杂任务 GraphRecursionError：recursion_limit 显式提到 300（引擎默认 100 触顶）
- 设置页/统计页崩溃：运行时配置全段兜底归一化、契约对齐
- 流式正文冻结：rAF 批处理在窗口后台化时挂起
- 标题拦截静默失效：沿原型链逐层查 title accessor
- 引擎 npm 镜像源透传、子代理启用链路接通、项目工作区沙箱接通
