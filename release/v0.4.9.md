# KCoder v0.4.9

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.2-alpha.2 (0a53fb5)

## 变更

- **工作区侧边栏折叠态账号头像修正**：头像放大至与上方折叠图标列同规格（28px 圆形），并修正两处定位缺陷——此前折叠后头像贴左缘不居中（行内元素参与上游 flex 布局把容器撑出双倍宽所致），修正后改为绝对定位居中；同时修正头像贴底沿的问题。现在折叠态头像与上方图标精确同轴，展开恢复「头像 + 用户名」行
- **Git 面板推送后自动折叠**（kcoder-git-panel 0.5.4）：提交和推送区域展开时，点击推送成功后自动折叠该区域，与提交成功后的行为一致
- **dsh-flowglass 插件解禁**：此前的退役清理清单误将其列为退役插件，导致用户手动安装后每次启动被自动清除；现已摘出——保持不预置，但不再拦截按需安装，手动安装的 dsh-flowglass 可正常加载并被内置侧边栏识别
- **状态栏终端图标尺寸对齐**（kcoder-terminal 0.1.8）：状态栏右端四枚按钮（侧栏面板/终端/上下文/Git）图标统一为 16px，修正终端图标略小 1px 的视觉不一致
- **设置 · MCP 服务器列表卡片化**：由 badge、开关、名称、命令、操作按钮挤一行的平铺列表升级为卡片列表——头行放启停开关、名称、内置/传输方式徽标与编辑/删除操作，完整命令行或 URL 独立成明细行；卡片悬停提亮、停用态整卡降透明，亮暗主题自适应
- **侧边卡片设置页版本号修正**：版本徽标显示的 0.17.1 来自上游产物内硬编码的服务版本常量（上游升版时未同步重建产物），实装包实为 0.17.2；新增收编物化版本对齐机制，以包 package.json 为权威自动改写产物常量，后续上游同类问题自动纠正

## 升级注意

- 无需手动操作：kcoder-git-panel 0.5.4 与 kcoder-terminal 0.1.8 随 in-box bundle 自愈机制自动物化；侧边卡片版本号显示在重启后即为正确值
