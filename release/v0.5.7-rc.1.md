# KCoder v0.5.7-rc.1

> 发布日期：2026-09-09 · 上游基线：deepseek-harness 0.1.3-alpha.2 (82a5fd6)，集成分支 kcoder/0.1.3-alpha.2
> 预发布版本：用于验证 agent 沙箱权限重复请求修复的候选版本。

## 修复

- **完全权限下重复沙箱升级不再阻断 agent**：当当前调用已经处于 `danger-full-access`，但工具请求再次携带同级 `sandbox_permissions` 时，运行时现在直接复用已授予的权限，不再报「not strictly wider」并提前终止命令。`workspace-write` 的同级重复请求同样按幂等操作处理。
- **发布 runtime 自动带上兼容修复**：发布物化阶段会对内置 `@deepseek-ai/dsh-sandbox` 编译产物应用严格锚定的兼容修复；如果上游编译守卫结构变化，构建会明确失败，不会静默修改未知代码。
- **内置 runtime 启动自愈**：升级到本版本后，内置 runtime 在首次解压和后续复用时都会检查并补齐该修复，避免旧归档内容在启动时重新暴露同一问题。

## 安全边界

- 仅放行“请求模式与当前有效模式完全相同”的幂等复用。
- `workspace-write` 升级到 `danger-full-access` 仍按原流程请求审批。
- 已处于完全权限时请求更窄模式仍然拒绝；工作区边界和文件写入策略没有扩大。

## 升级注意

- 这是候选版本，建议先在需要完全权限 agent 的测试项目中验证，再作为稳定版本推广。
- 安装包升级后需要完整重启 KCoder/dsh，运行中的旧进程不会重新加载已修改的 runtime 模块。
- 当前已安装的旧版本不会自动获得本版本的桌面端自愈逻辑；如问题正在阻塞工作，可先对当前机器的 runtime 使用临时热补丁，之后仍建议升级到本版本。
- 本版本不涉及会话数据、模型配置或工作区文件迁移。

## 发布验证

- 沙箱热补丁回归：2/2 通过，包含未修复行为对照、同级复用、真正非加宽请求拒绝、重复应用幂等和编译守卫变化失败保护。
- `pnpm run typecheck`：通过。
- `pnpm run build`：Electron 主进程、preload 和 renderer 构建通过。
- 构建产物已确认包含 runtime 自愈逻辑，未修改仓外 DSH checkout。
