# KCoder v0.6.30

> 发布日期：2026-10-10 · 上游基线：deepseek-harness **0.2.1-alpha.2**（`d7432673`）+ fork 集成分支 `kcoder/0.2.1-alpha.2`（`41f151ab20`）——引擎基线不变；本版含**一处静默数据损失修复**、**agent 预设统一为单一 PTC 模式（破坏性）**与一组界面字号/几何对齐。

## 新特性

### agent 预设统一：四模式裁为一，全部跑在 PTC 上

- 原标准 / 编码 / 极简 / 创造四个 agent 预设**收缩为单一模式**：工具呈现统一为 PTC（`run_code` 程序化调用，多次往返合成一次程序调用）；创造模式的运行时自省工具、创作技能目录与插件管理**并入**；workflow 工具按上游 PTC 纪律保持停用（编排统一走 `run_code` 程序）。
- **界面上不再出现任何预设选择面**：设置页预设管理、新任务英雄条的模式选择、会话头预设徽章全部移除——模式在后台运行，用户零决策。
- **第三方技能插件不受影响**：技能发现层与工具呈现层是正交的两套机制，插件贡献 / 用户目录 / 项目目录三条发现通道照常工作（已装的 super-ppts、animations 的 runtime 技能实证在册）。

### 历史会话迁移窗口

- 首次启动新版本时，若检测到使用旧预设的历史会话，会先弹出**「会话模式迁移」窗口**：列出会话标题 / 路径 / 日期（93% 以上有标题，可搜索、逐条勾选或全选），确认后把所选会话改写到新模式；**原始文件自动备份（`.bak-preset`）**，迁移幂等，可反复运行。不迁移的会话保留在列表中但无法继续对话。
- 菜单「文件 → 迁移历史会话预设…」可随时再次打开（引擎运行中会引导重启后执行）。

## 修复

- **你自行安装的 `@kkutysllb/dsh-git-panel` 每次重启后被静默清除、需要重装。**

  根因（**纯我方 bug，已在隔离 profile 上复现并验证修复**）：内置插件退役名单 `RETIRED_PLUGINS` 里持有该插件的**现行全名**。它 2026-09-14 因「右侧栏的 Git 面板已完整覆盖其能力」被退役——而**那个右侧栏插件已于 2026-10-09 整线退役**，退役理由不复存在；名单却是**每次启动三清**（依赖声明 + bundles 层叠 + node_modules 实体），于是用户装好的插件在下一次启动被静默删掉声明与实体。

  证据链：`.plugin-manager` 的安装日志里对它的操作**全是 `+`（安装），没有任何 `-`（卸载）**——说明不是卸载，而是启动期被删；把真实启动函数放到隔离 profile 上跑，复现出 `[kcoder-bundle] 清除 profile 退役/孤儿插件残留: deps=[@kkutysllb/dsh-git-panel] bundles=[@kkutysllb/dsh-git-panel]`，三个函数跑完后 deps/bundles/实体三者尽失。移除该名单项后同一复现中三者**全部存活**。

  修复：从退役名单移除该插件（un-retire，同 dsh-file-review-kcoder 的先例），并把「名单不得含 git-panel 系（含现行全名）」做成静态断言。**判据教训入档**：退役理由被后续退役动作推翻时，必须同步复查所有依赖该理由的名单。

- **标题栏几何对齐**：左侧按钮组从 26×26 放大到 **28×28 / 圆角 8px**，与右栏折叠按钮逐参数同几何；任务标题字号降为内容阶梯（跟随用户字号设置）。
- **界面字号全面对齐内容阶梯**（以技能分区的 13/12px 规格为准）：MCP 服务器分区、关于页、「返回工作区」按钮、数据迁移面板、账号菜单、更新气泡——原先全部继承根字号（≈16px）普遍偏大，现统一为上游字体 token 阶梯，**跟随应用字号设置联动**。

## 验证

- 隔离复现（真启动函数 + 临时 DSH_HOME + 真 profile 拷贝）：修复前三者尽失 → 修复后 deps/bundles/实体**全部存活**。
- 预设统一与迁移窗口：策略层结构不变量 + 迁移逻辑合成夹具 **61/61**；真 Electron GUI 冒烟 **12/12**（窗口弹出→标题渲染→默认全勾→迁移落盘→`.bak-preset` 在位→重启后再扫归零）；真机只读试扫 939 候选 2.3 秒、93% 有标题。
- 字号/几何：注入面门禁（禁写死 px 字号）全绿 + 逐面负向对照（写回裸 px 即点名报错）；`pnpm check` 全电池 **39/39**。

## 升级注意

- **首次启动可能出现「会话模式迁移」窗口**（检测到旧预设会话时）：全选确认即可，原始会话文件自动备份 `.bak-preset`，可随时重跑；不想迁移的逐条取消勾选。
- 升级后重新安装一次 `@kkutysllb/dsh-git-panel`，此后**重启不再消失**。
- v0.6.28 / v0.6.29 用户建议直接升到本版（0.6.29 已含终端权限、持久终端 entry、两个子智能体、锚点归一四处修复）。
- 又及：另一个仍在退役名单的现行名是 `@kkutysllb/dsh-terminal`——那是**有意的产品级退役**（终端交回上游原生），同样会在每次启动被三清；若你希望「装了就留」，说一声我把口径改成「只退役一次」。
