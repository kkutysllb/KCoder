# KCoder v0.5.0

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.2-alpha.3 (dd6322d6)

## 变更

- **上游基线升级 0.1.2-alpha.2 → alpha.3**：引擎全面升级，以下新能力随基线带入
- **长会话轮次导航与跳转**：对话视图新增右侧轮次导航条，可预览各轮次摘要并点击跳转；跳转目标轮次尚未载入本地窗口时自动向后翻页加载到位，长会话翻阅历史不再需要手动一页页「加载更多」
- **长会话渲染性能优化**：会话渲染内存占用下降，代码块语法高亮改为视口外延迟执行，长对话滚动更流畅
- **运行中排队图片可靠回显**：会话运行期间提交的排队/插队消息附带图片时可靠投递与回显，含持续子代理的后续消息场景；排队消息新增「插队（steering）」呈现标记
- **命令菜单 Tab 补全**：输入 `/` 唤出的命令菜单支持 Tab 键补全
- **read_image 按内容识别无扩展名图片**：附件读取对无扩展名图片按文件内容识别格式，不再误判为文本
- **权限标签多语言**：权限预设标签随界面语言本地化
- **模型目录更新（pi-ai 0.84.4）**：新增 glm-5.3-flash / glm-5.3-highspeed 等模型目录
- **连接稳定性修正**：后端短暂卡顿不再被误判为断连而终止会话（WebSocket 心跳改为连续漏跳计数制）
- **定时计划列表窄视口修复**：窄窗口下计划目录列表对齐异常修正

## 内部维护

- 上游基线升级以集成分支重建：fork 五修复分支（pi-ai 升级 ×2、codex 协议回退、markdown 跨行合并、projection 缓存隔离）与品牌化、imageRequestPricing 两笔 cherry-pick 全部在 alpha.3 上重新合入，与上游的 2 处集成冲突已双侧合并，差异文件列表与上游完全一致（完整性断言通过）；全部注入锚点逐项核对存活
- upstream/0002 归档改名对齐 pi-ai 终态 0.84.4（维护记录，不影响构建）

## 升级注意

- 无需手动操作：基线升级为全新引擎产物，重启 KCoder 即生效
- 上游移除了可选的 SQLite 会话持久化后端；KCoder 默认使用 JSONL 持久化（从未启用该可选后端），存量会话数据不受影响
