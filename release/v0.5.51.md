# KCoder v0.5.51

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.3-alpha.1 (d347e703)

## 修复

- **Windows 全新安装引擎启动即崩（cannot resolve profile bundle @kkutysllb/dsh-file-attach）**：文件/文件夹附件插件自 0.5.1 起漏配安装包资源映射（extraResources）——仓库内置清单有它、插件页也显示为内置，但安装包里从未携带实体；引用此 bundle 的 profile（用户经插件页安装过、或迁移自含它的旧数据）引擎启动即崩，全新安装场景直接无法使用。本版补上映射：附件插件实体随包分发，启动自动物化，历史受影响 profile 自动修复（实体缺失即重建）。
- **Windows 数据迁移报「没有权限 rename」**：Windows 与 POSIX 不同，旧目录树内任何句柄未释放（引擎子进程退场延迟、杀毒软件/索引器实时扫描）整库搬移即报无权限。现搬移带指数退避重试（约 4 秒窗口消化句柄释放延迟）；仍失败时错误提示给出 Windows 针对性指引，引擎在旧目录原地恢复、可重试。
- **CI 发布链补内置插件对账闸**：本地打包验证有「内置插件随包对账」，CI-only 发布链一直没有——这正是附件插件漏配五版未被发现的原因。新闸在打包后逐目录对账 bundle/ 清单与包内 resources，并核对插件热补丁，缺任一即拦截发布。

## 升级注意

- **Windows 受影响用户**：升级后首次启动自动修复附件插件实体，无需手动操作；数据迁移此前报「没有权限」的，在设置页重新发起即可（已带重试；仍失败请先关闭占用旧数据目录的程序）。
- **macOS / Linux 用户**：无行为变化，可正常自动更新。
