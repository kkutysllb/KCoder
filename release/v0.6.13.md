# KCoder v0.6.13

> 发布日期：2026-09-15 · 上游基线：deepseek-harness 0.1.6-alpha.1 (0a15e36e7f)，集成分支 kcoder/0.1.6-alpha.1（尖端 b88abcad16）

## 基线升级（0.1.5-rc.2 fb2c4b9e → 0.1.6-alpha.1 0a15e36e7f）

800 提交 / 3942 文件（代码面 2787）。契约层逐项核对结论：`ui-slots` / `ui-layout` / `ui-sidebar` **源码零改动**（slot 注册表契约稳定）；`SESSION_FORMAT_VERSION` 仍为 **3**（无会话迁移）；KCoder 全部注入锚点存活（证据见「发布验证」）。

集成冲突 6 处：ui-chat 三处（上游新增必填 `openSkill` × 我方 0007 `editUserMessage`，参数取并集）、session-projection-cache 双语 README、pnpm-lock（重收敛）。

## 随基线引入、已在产品面启用的能力

- **MCP 资源能力**：可发现并读取 MCP 服务器资源、使用 URI 模板（base 层 `mcp-resources`，永远挂载）；配合内置的 6 个 MCP 服务器（context7 / fetch / playwright / memory / sequential-thinking / zai）开箱可用。
- **MCP 客户端升官方 SDK v2**：协议协商、工具分页、支持未提供工具的服务器。
- **Node PTC `run_code` 按次超时**：默认 120 秒、最多 600 秒。
- **归档会话恢复**：设置页新增「已归档会话」分区，可一键恢复（此前归档后无恢复入口）。
- **Trajectory 增强**：JSON 字符串展开/复制、PTC 代码与调用结果查看、推理默认展开、恢复记录中的运行耗时。
- **推理与压缩摘要标题吸顶**：展开后标题随滚动固定，可折叠且不遮挡代码复制按钮。
- **输入框菜单重构**：加号菜单分「添加 / 命令」两组并中文化；文件添加入口并入菜单、移除独立回形针按钮；斜杠菜单中英命令统一展示。
- **连接状态与耗时**：区分自动/手动重连并支持点击重试、减少提示闪烁；轮次超过 1 小时后耗时按小时·分·秒显示。
- **DeepSeek V4.1 图片与请求优化**：调整图片缩放与 Token 估算，提高默认请求图片尺寸与编码质量。
- **稳健性修复**：持久 Bash 处理大历史输出的效率；Web 服务恢复后的模块路由注册；可选插件启动失败不再影响其他可用插件（必需插件失败仍退出）。
- 以及一批会话与交互修复：会话最近更新排序与刷新后手动顺序保留、新建空白会话置顶、按轮次分叉不再带入后续输入与设置、PTC 提示词双花括号、Linux 子进程终止与清理判定、短 Markdown 表格 hover 跳动、文件编辑卡片按行展示改动与上下文（含增删行数统计修正）、子代理完成通知改传正文。

## 本产品的适配与产品决策

- **原生右侧栏外壳压制**：保留 `ui-sidebar-right` 的服务层与契约（ui-chat / ui-reference / ui-skill / ui-sidebar-files / ui-sidebar-documentpreview / ui-sidebar-terminal 六包在 `dsh.client.inject` 里硬声明它，禁用会让主对话链整体挂掉），只摘用户可见外壳（`data-sidebar-right-expand` / `-panel` / `-float-host`）。文件打开由内置 `dsh-coding-sidebar` 的 openpath 拦截重定向进自家编辑器。
- **产品策略层（`dsh web --patch`）**：新增 `$DSH_HOME/cordis.patch.kcoder.yml`，由宿主以 `--patch` 注入（overlay 层最后应用，覆写上游 bundle 行）。两层策略：
  - **会话日志不上传**：上游 0.1.6 起 `session-log-deepseek` 的 `enabled` 默认 `true`，会把完整未接受的会话日志（消息正文、工具参数与结果、工作区路径、反馈）随请求上报；KCoder 显式关闭。
  - **原生终端整行禁用**：终端由内置 `@kkutysllb/dsh-terminal` 承担；宿主 `api-terminal-controller` 保留（api-remotes 静态 `$mount` 它的 remote）。
- **内置插件镜像同步**（sync-bundles 对账归零）：`dsh-coding-sidebar` 1.0.12 → **1.0.16**（sidechat 发送图标自持化——上游 0.1.6 删除 `IconSendOutline16`，产物里缺失导出变 `undefined`，渲染 sidechat 时会抛 Element type is invalid；peer 范围放宽为 `^0.1.5-rc.2 || ^0.1.6-alpha.1`）；`dsh-file-review-kcoder` 1.0.3 → **1.0.4**（peer 范围同样放宽）。随包内容仅服务全新安装，已安装用户经插件管理页独立升级。

## 本版未启用 / 已由内置实现替代的上游能力

> 上游 0.1.6 发行说明包含以下能力，但在 KCoder 默认组合中**不可用或走的是另一条实现**，列此避免误解：

**默认不挂载（需显式启用）**

- 实验性 Auto review 模式（上游默认 Web 亦不含）
- 实验性 Browser Use：Playwright MCP / Chrome DevTools MCP / Stagehand
- 实验性 Computer Use：Cua Driver MCP / native
- SSH 远端工作区
- Headless：stdin 任务、`--session-id`、`--json` 运行事件

**已由内置实现替代（上游那套在 KCoder 不可见）**

- 上游右侧栏的**文件预览优化**（保留文件树滚动位置、图片与 PDF 随面板适配、简化预览器选择）——原生右侧栏外壳已压制；预览走内置 `dsh-coding-sidebar` 自带 viewer（含 Office / 视频）。
- 上游 **Web 终端的文字与光标对比度、主题配色保留**——原生终端行已禁用；终端走内置 `@kkutysllb/dsh-terminal`。
- 「文件 / Skill 引用与交付文件链接默认由侧边栏预览」**行为保留**，但落点是内置侧边栏编辑器，而非上游原生侧栏。

**不属于本产品交付物**

- 文档站的 Mermaid 图表全屏 / 缩放 / 平移（上游 `website/`）。
