# KCoder v0.5.7

> 发布日期：待发布时填写 · 上游基线：deepseek-harness 0.1.3-alpha.2 (82a5fd6)，集成分支 kcoder/0.1.3-alpha.2

## 修复

- **llm-pi-ai 配置 opencode 模型恢复可用（400 MissingSessionID 根治）**：OpenCode Go/Zen 网关自某时点收紧策略——缺 `x-opencode-session` 会话路由头的请求直接回 400，而 pi-ai 库（0.84.2→0.85.1 均如此）从不发送该头（pi 客户端的注入在其 SDK 层，llm-pi-ai 走的库路径收不到）。本次在 llm-pi-ai 引擎适配层补齐：opencode/opencode-go/ln 端点自动携带 `x-opencode-session`——取值引擎会话 id（conversation 级稳定），无会话时每适配器稳定兜底；部署在模型配置里显式写过的该头永远优先（KCoder 0006 修复）。
- **中继/网关兼容修复随 pi-ai 0.85.1 重打继续生效**：codex 通道普通 API key 的 accountId 解析回退、翻译型中继缺终止事件的合成收尾、无 codex 通道时自动降级 openai-responses——三项 pnpm 补丁全部重打到 pi-ai@0.85.1（补丁内容零漂移），行为与 0.5.6 一致。
- **上游 alpha.2 自带修复带入**：subprocess 代码运行时原生容器化重构（69 项修复）、会话引用/恢复、chat 滚动锚定、system-prompt 结构、Windows Python 运行时等待等（详见上游 0.1.3-alpha.2 发布，316 commits）。
- **用户气泡「编辑并重发」回归**：已发送的用户消息气泡新增铅笔入口，点击将消息文本回填到输入框（光标落尾），修改后按新消息重发。该入口曾随附件插件线退役（v0.5.1 宿主补丁链摘除）而消失；本版以引擎纯 UI 方式恢复（不动会话存储与 agent 流程，仅文本回填；上游将来提供原生同会话编辑后可撤除此补丁）。带图片/附件的消息仅回填文本部分（KCoder 0007 修复）。

## 引擎升级（0.1.3-alpha.1 → 0.1.3-alpha.2）

- **pi-ai 0.84.4 → 0.85.1**：模型目录原生补齐——glm-5.3 / glm-5.3-flash 等此前依赖 KCoder 修复分支供给的目录缺口随上游目录原生消失（0002 升级适配退役）；0.85 协议兼容面扩展（reasoning 预算分档字段、vllmPriority 等随模型页能力自然开放）。
- **open-in-app**：Web 会话头新增「在已安装应用打开 workspace」分体按钮（引擎 bundle 新增 ui-open-in-app / host-open-in-app 一对包；本版打包产物自动包含）。
- **会话与渲染性能**：session 持久化流式迁移 + 历史读取提前物化；长会话不再展开回放已结算的 assistant 流（内存与渲染优化）；agent 模型切换提示、message freeze 复用等。
- **KCoder 适配层核对结论**：全部注入锚点（railMark/brandName、turnTail slot、composer DOM、sendSession 5 参、settings slot、sidebar/centerCol、selectProducedFiles）经 alpha.1→alpha.2 逐项核对存活，零契约破坏；第三方插件锁版继续有效。

## 升级注意

- **开发/运行时物化须与新集成分支对齐**：引擎 pin 已切至 `kcoder/0.1.3-alpha.2`，重新执行 `bash scripts/setup.sh` 物化运行时。open-in-app 是 alpha.2 新增引擎包，旧（alpha.1）打包运行时缺失它——直接用开发引擎 + 旧运行时混跑会报 loader `ERR_MODULE_NOT_FOUND: dsh-client-ui-open-in-app/lib/index.js`（产品更新到本版后自动消除，因打包产物含新包；开发态需以新集成分支重新 setup 并对新包构建 lib）。
- **subprocess 重构含 landlock 原生包（仅 linux-x64/arm64）**：macOS 产物不受影响；发布链仍按 Electron node 形态物化 smoke 全部原生模块（v0.5.5 同口径）。
- **turn-tail 渲染行为**：上游不再展开回放已结算流的实现使长会话尾部渲染语义略变，涉及该区域的自定义插件请回归。
- **发布链**：`package.json` 版本号与自动更新通道于发布时同步。
