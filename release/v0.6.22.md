# KCoder v0.6.22

> 发布日期：2026-10-02 · 上游基线：deepseek-harness **0.2.0-rc.2**（639ed01539）+ fork 集成分支 kcoder/0.2.0-rc.2（b428f93a79）（与 v0.6.21 同基线，本版为上下文插件退役 + 三处界面精简 + 技能停用/恢复）

## 新特性

### 技能面板支持「停用 / 恢复」

设置 → 技能页此前只能把随包可选技能「启用」，用户全局技能装上之后没有退回途径。本版补齐闭环：

- 「用户全局技能」每行新增**停用**按钮：整目录移入 `$DSH_HOME/skills-disabled/<来源>/<名>/` 暂存（引擎不扫描该目录，技能当次会话即失效；文件原样保留，可随时恢复）。
- 新增「已停用（可恢复）」分区：暂存技能在此列出，点**恢复**移回原来源目录（用户目录 / `~/.agents` 共享目录各自归位）。
- 同名冲突双向拒绝（恢复时生效层已有同名、停用时暂存区已有同名），不覆盖任何一份数据。
- 说明：引擎没有技能级禁用开关，「停用 = 移出扫描根」是唯一可靠实现。注意共享目录（`~/.agents/skills`）里停用的技能，Claude Code 等同样读取该目录的工具也会一并不可见。

### 界面精简（三处）

- **侧边栏折叠态**：折叠后的图标列不再显示「新建工作区」与「搜索」两个入口，折叠态更简洁。需要时展开侧栏，两者功能照常；搜索快捷键的「展开并聚焦」路径不经按钮，不受影响。
- **设置对话框**：移除头部「打开配置文件」按钮与「×」关闭钮（连同头部空条）。关闭改用 **Esc 键**或**点击对话框外的遮罩**，两条路径均保留。
- 这两处为对上游外壳的显示层压制（锚定稳定属性/类名后缀），上游改名时压制静默失效（按钮复现），不影响功能。

## 修复 / 内部

- **上下文插件（dsh-context）彻底退役**，按内置插件退役原则三清：依赖声明、常驻补丁、宿主注入入口（含冒烟脚本）全部移除。
  - 上一版为它重出的两条常驻补丁（RO 回路冷却、上下文跳转走会话内 tab）随插件退役一并下线。
  - 补丁链由此进入**零常驻补丁稳态**：`profiles/web/patches/` 只留 README（目录锚），发版闸对空补丁清单放行。
  - 自愈机制会在升级后首次启动时回收已退役插件在本机 profile 的现场（声明、物化目录、补丁应用痕迹），无需手动清理。
- 全仓审计：三门（typecheck / lint / 安全漏洞）全过，报告项与上一版完全一致（零新增发现），详见 `release/audit-v0.6.22.md`。

## 升级注意

- 从旧版升级后，**上下文插件不再可用**（产品决策退役）；本机 profile 的残留由自愈在首次启动时回收。
- 侧边栏折叠态看不到「搜索 / 新建工作区」属预期——展开侧栏即可使用。
- 设置页关闭方式变为 Esc / 点遮罩（原「×」已移除）。

## 已知问题（沿用登记，与本版无关）

- `smoke-panel-buttons` 冒烟失败：标题栏第四枚按钮的平移规则从未写入 `SHIFT_JS`（v0.4.6 起如此）。
- `smoke-skills-dom` / `smoke-skills-page` 冒烟挂起：构建期插值常量与冒烟提取方式不匹配（v0.5.9 起如此）。
