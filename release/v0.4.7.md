# KCoder v0.4.7

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.2-alpha.2 (0a53fb5)

## 变更

- **内置插件真源迁址 dsh-plugins 仓**：六个内置插件（git-panel/stats-panel/terminal/language/skills/file-review）的源码与产物统一收进 kkutysllb/dsh-plugins monorepo（另含 file-review、better-sidebar 两个 fork 的源码仓）；KCoder 仓 plugin-forks/ 撤销，bundle/ 转为随包分发的同步副本。新增 scripts/sync-bundles.mjs 单向同步（dsh-plugins → bundle/，--check 对账），发版 verify 对账不通过硬拦——插件改动未同步真源就打 tag，发布直接红。随迁 file-review bundle 从 0.5.4 升到真源仓已有的 0.5.5
- **退役内置识图预置插件 dsh-vision-router**：工具式识图与多模态主模型的原生视觉能力抢调用（模型优先走插件识图工具，效果反而一般），多模态已成主流，原生能力优先。预置清单摘除，老用户 profile 已装的 dependencies/bundles 声明与 node_modules 实体三处自愈清理（启动时幂等执行，无需手动卸载）。同时确立预置冻结原则：第三方插件不再新增预置，用户按需自装（现有 context/better-sidebar/archify/drag-to-attachment 维持现状）
