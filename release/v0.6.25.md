# KCoder v0.6.25

> 发布日期：2026-10-05 · 上游基线：deepseek-harness **0.2.1-alpha.1**（`5badb15009`）+ fork 集成分支 kcoder/0.2.1-alpha.1（`161c7122f6`）——引擎基线**不变**，本版是产品面与内置插件的收口

## 新特性

- **标题栏与上游对齐：会话说得清、状态徽章点得动。** 标题栏主文本此前显示的是「DSH 本地构建」——那不是产品名，是**构建态标识**：上游把产品名做成**构建期内联**的 `DSH_CLIENT_TITLE`，本产品的引擎构建没有内联它，于是回退到了本地化串。现在主文本读会话面包屑（与上游 `DocumentTitle` 同源、但不带产品名后缀），显示为「工作区 / 会话标题」。

  同时把**上游注册在会话页头状态槽里的四类徽章**搬进标题栏并放开交互：**智能体团队**（成员与任务，带状态点）、**代理任务**、**后台任务**、会话预设。此前整块页头被收起来换纵向空间，四类徽章一起消失，只有会话预设被一条旁路以「自绘合成徽章」补了回来——**合成副本不是对齐**（不可点、不随状态变化、上游每加一个徽章就要多写一条旁路）。现在上游加多少徽章就自动显示多少，位置也照上游排布紧跟标题之后（而非堆在右侧）。

- **内置终端 1.3.0：看得清、点得准、边缘不再毛。** 每个标签前置终端图标；header 右侧显示当前活动标签**真实使用**的 shell 短名（`zsh` / `bash` / `pwsh`…）——取服务端算好的实际落点，**不按平台猜**（猜会在两种情况下说谎：用户自定义了 `$SHELL` 时、以及回退到 bash 时）。「边框痕迹粗糙」的根因是面板上缘被刷了一条 4px 实心分隔色：现在拖条常态隐形、悬停浮出胶囊、按下染强调色，面板补上 1px 上分隔线 + 10px 上圆角 + 向上投影，分隔色改由既有主题 token 现算（旧版硬编码的黑色透明在暗色下会脏成灰线）。

- **内置侧边栏 1.0.39：点交付物文件的「查看变更」终于能看见文件。** 上游交付物卡把这个手势交给**原生右栏**，而原生右栏面板是本产品有意压制的（产品铁律 1）——该地址族此前没有任何一方认领，于是穿透到被压制的面板，用户得到**一条空白列、文件从不出现**。现在由插件认领该地址族，打开的文件进自家编辑器，与内建审查页签「检视」按钮同一落点。

- **技能面收口：内置技能只留与编码有关的。** 退役 6 个非编码内置技能（`image-generation` / `video-generation` / `music-generation` / `podcast-generation` / `comic` / `deep-research`），技能注册面 **37 → 31**；「设置 → 技能」里的**「多媒体模型」分区整块移除**，宿主也不再向引擎注入 `media-models.env`。

## 修复

- **修掉一类「看得见但点不动」的故障（用户实测）。** 会话页头搬进标题栏后，徽章肉眼可见却完全点不动。根因**不在样式层**，而在 **Electron 原生窗口的拖拽区合成**：它按几何 + **DOM 顺序**、**忽略 CSS 层叠**判定「这一点是拖窗还是交给页面」，而本产品的桌面壳**从不写上游那张 app-region 表所依赖的平台标记**，导致上游整层「可交互元素削减」在真机上一条都不生效——整条标题栏只有一个拖拽盒子，覆盖之处点击全被吞掉。本版按上游同一语义自补该层（作用域不依赖平台标记）、把标题栏拖拽基座排到内容之前、并让页头覆盖层**不参与**合成。附带记录两条浏览器实测事实（与上游代码注释不符，以实测为准）：`-webkit-app-region: none` 被解析成 `no-drag`（不是「无」），且该属性**会继承**。

  **判据也跟着换了**：上一版冒烟是用「DOM 命中」判定「可点」的，而上游自己的端到端注释明说这一类**不能用「点一下试试」来判**（吞发生在原生窗口层）——所以上一版报绿而现场点不动。现在改用上游的合成模型（收集拖拽盒子 + 判定该点归属），并把「真实宿主形态」（不带平台标记）设为夹具默认。**这一类「结构上不可能变红」的假绿，比没有测试更危险。**

- **退役工作区统计徽章（与上游重复渲染）。** 工具行里出现了两枚 `+n/−n`：一枚是上游自带的 diff 统计，另一枚是本产品早先为文件徽章补的。保留上游那枚，退役本产品这枚及其**整条数据链**（页面统计通道、历史补拉拦截、按回合的变更摘要拉取、轮尾探针、按工作区分桶的活动表）——顺带也去掉了那些后台轮询。**保留**文件**类型**徽章（TS/JS/MD，与上游无重复）与工作区探针（设置页「工作区项目技能」依赖它探位）。

- **修掉「点尾卡文件留一条空白」的静默回归。** 内置「改动审查」插件退役后，原生右栏的布局轨道没有被归零，点交付物尾卡的文件会在右侧留出一条空白列。

- **修掉会话头那个「…」。** 按产品指定移除（它是上游会话日志导出与反馈的入口菜单）。同座位里的另一枚工具按钮照旧保留。

- **内置技能包首次真正带上 office 批的脚本载荷（`dsh-skills-bundle` 1.0.4）。** 这一批（docx / pptx / xlsx / pdf / microsoft-foundry）的卖点是「启用后 agent 可直接执行 `scripts/*.py`，离线纯本地」——但**这个承诺从未成立过**：同步脚本把 `scripts/` 目录当作任意深度排除，**198 个脚本与模式文件**（7.4 万行）在三层（真源 / 镜像 / 随包副本）被一致地剔除，而所有静态检查都是绿的（镜像与对账走同一份排除逻辑——**一致地一起错**）。现已修正排除规则只在仓库根生效，并对 `skills/` 载荷加上「零排除」不变量断言，防止复发。

## 升级注意

- **6 个非编码技能消失**：`image-generation` / `video-generation` / `music-generation` / `podcast-generation` / `comic` / `deep-research`。这是产品决策（内置技能只留与编码有关的）；如仍需使用，可经插件/技能市场自行安装。
- **孤儿凭据文件（不自动删除）**：`~/.kcoder/media-models.env` 此前用于保存多媒体模型的密钥，本版之后既无生产者也无消费者。它**不会被自动删除**（可能含你的明文 API Key）——确认不再需要时请自行删除，或先备份其中的凭据。
- **npmmirror 镜像滞后**：内置侧边栏 1.0.39 在 npmjs 已发布可见（指定版本端点 200、`latest` 已指向），npmmirror 侧仍在追赶（该包体积大、镜像同步滞后）；使用 npmmirror 作为 registry 的用户，若安装时解析不到该版本，切回 npmjs 或稍后重试即恢复。详见 `release/audit-v0.6.25.md`。
- 无需手动迁移；重启应用（或托盘「重启引擎」）即生效。
