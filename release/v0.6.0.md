# KCoder v0.6.0

> 发布日期：2026-09-12 · 上游基线：deepseek-harness 0.1.5-rc.2 (fb2c4b9e)，集成分支 kcoder/0.1.5-rc.2

## 新特性

- **Agent 浏览器实况（CDP 远程渲染）**：桌面端新增浏览器宿主——常驻无头 Chromium（独立 user-data-dir，登录态跨任务持久，固定 CDP 转发地址 127.0.0.1:9223）。playwright MCP 改连该宿主（`--cdp-endpoint`），**agent 浏览不再弹本机 Chrome 窗口**；侧边栏浏览器 tab 新增「Agent 实况」：`Page.screencastFrame` 实时渲染 + 鼠标/滚轮/键盘回传（输入坐标按视口比例换算），target 列表自动跟随最新页 + 下拉钉住。
- **Agent 一用 playwright 自动切实况**：浏览器 tab 轮询浏览器宿主的 page target——出现 agent 页面（非 about: 空页）即自动开实况并把浏览器 tab 顶到前台；一次性语义，之后用户手动关闭不会被强制重开。
- **发版前置审计规定**（流程）：`release.sh` 新增 `audit` / `prepush` 命令；`ship` 强制校验审计报告并重跑审计与全量构建——typecheck / lint 0-error / 生产依赖安全漏洞为硬门，死代码 / 冗余依赖逐条处置。

## 修复

- **macOS「跟随系统」主题失效**：偏好上报链路保留完整查询串（不再丢 `?token=`），boot 偏好正则放宽空白变体；`nativeTheme 'updated'` 监听在跟随档下主动重同步窗口 chrome。
- **Windows 深→浅→深后标题栏控制按钮区卡浅色**：`setTitleBarOverlay` 连续调用可能被 DWM/Electron 丢弃，改为立即一次 + 60/200ms 两次幂等重放。
- **Windows 任务执行弹 cmd 窗口**：桌面侧全部 11 处 `spawn/spawnSync` 统一 `windowsHide: true`，引擎以隐藏控制台运行、工具子进程继承。
- **js-yaml@4.3.1 高危漏洞**（GHSA-2883-xcg3-v3hh）：electron-updater 传递依赖经 overrides 提升至 4.3.2，官方 audit 端点复检无漏洞。
- **死代码清理**：`upstream.ts` 零消费者导出 `isSyncing` 移除；smoke 脚本 13 处 lint 警告清零（未使用导入/死变量/多余转义）。

## 变更与退役

- **退役内置 dsh-stats-panel**：上游 0.1.5 composer dock 原生 StatsPills（轮次/步数+输出速度、总 token+缓存命中双 pill + 时间速度与 token 用量对话框）完整覆盖插件能力；旧物化目录与注册首启自愈清理。
- **退役内置 dsh-language-bundle**：产品决策移除「强制中文回答」能力；配套通用设置「回答语言」行、patch 托管块管理链一并下线；开过强制中文的用户，patch 托管块首启自动剥离（带顶层数组硬校验，杜绝剥离写坏文件）。
- **内置 dsh-coding-sidebar 1.0.4 → 1.0.6**：文件预览线移除（维护者决策，与已卸载的两个衍生插件依赖面一致）；新增「Agent 实况」与自动切换；0.1.5 宿主 API 对齐（snapshotEvents / handle-seam / isSeeded）延续。
- **内置 dsh-skills-bundle 1.0.1**：补全 brainstorming `visual-companion.md` 操作约定（修复 SKILL.md 悬空引用）；安装说明对齐三途径；smoke 新增伴随文件引用一致性校验。
- 内置 dsh-terminal / dsh-file-review-kcoder 同步镜像已发版内容。

## 升级注意

- 基线 rc.1 → rc.2 为小步演进（消息反馈 + 交付物打磨），锚点与持久层零触碰。
- 首次启动自愈：stats-panel / language-bundle 的旧目录、注册与 patch 托管块自动清理；「回答语言」设置项不再出现。
- 浏览器宿主需要系统 Chrome 或 playwright chromium（缺失时 agent 浏览不可用并记日志）；CDP 转发端口仅绑 127.0.0.1。
- 常驻无头 Chromium 约占 200MB 内存；「Agent 实况」需在侧边栏浏览器 tab 手动开启一次（会话内保持，自动附着最新页）。
