# KCoder v0.5.8

> 发布日期：2026-09-11 · 上游基线：deepseek-harness 0.1.5-rc.1 (183f08e9)，集成分支 kcoder/0.1.5-rc.1

## 新特性（随上游基线 0.1.3-alpha.2 → 0.1.5-rc.1 引入）

- **右侧栏全新体系**：新增 ui-sidebar-right 包（dockkit 可逆停靠引擎），文件树懒加载、文本分页预览，Mermaid / Graphviz / SVG / 图片 / 文档预览全家桶，tab 导航与浮动面板。
- **插件开放 UI 通道**：`sidebar.right.pane.tab`（keyed，自定义侧栏 tab 类型）、`sidebar.panellist`（左侧栏「新任务/工作区之间」的图标行）、`main`（主面板）等一等 slot，第三方插件可原生接入侧边栏，无需 DOM 注入。
- **workspace-files 资源体系**：dual-face 文件 API、Client resource registry、会话/绝对路径资源地址、bounded byte-range 读取。
- **会话格式 V3**：canonical envelopes 重构、system prompt 进入历史、goal resume、durable inbox 恢复；旧会话自动迁移。
- **模型**：DeepSeek V41 Flash 成为 Chat Completions 默认模型；V4 / V4 Flash Vision Exp 目录可选。
- **运行时升级**：claude-agent-sdk 0.3.263、@openai/codex 0.153.4；llm-pi-ai 适配 pi-ai 0.85.1。
- 长会话渲染内存与代码高亮流畅度优化；子代理父子目录观察、实验性 agent-team；连接异常状态显示与自动重连。

## 修复

- 品牌注入器 hero 锚点适配 0.1.5（headline 单层 span 重构为 titleGroup 包裹），桌面 Logo 与 slogan 替换保持生效。
- 物化链工作区扫描区跟进上游原生产地改名（native/landlock-run → native/system），flock 锁改由预编译 N-API 包供给。
- verify-inject 脚本 `__DATA__` 占位符未替换的存量缺陷（脚本自检必然抛错）。

## 升级注意

- **上游原生体系重构**：`fs-ext` 移除，改用预编译 Node-API flock（native/system）；桌面运行时不再需要 ABI 重编步骤。
- **Session 格式 V2→V3、projcache 域版本 v6→v7**：引擎读兼容 + 自动迁移，旧会话首次打开时冷读重建，无需手动处理；迁移产物兼容由引擎兜底。
- **上游版本号 0.1.3 → 0.1.5 直接跳号**（0.1.4 静默跳过，无兼容性含义）。
- **内置 dsh-coding-sidebar 同步 1.1.0**（0.1.5 宿主 API 对齐：Session.snapshotEvents、persistence handle-seam、meta.isSeeded、dsw 变量映射），修复 0.1.5 下侧聊天 / 后台任务 / 子代理活跃度路由。
- Node 要求不变（^22.19 || >=24），pnpm 11；不涉及会话数据迁移以外的本地配置变更。
