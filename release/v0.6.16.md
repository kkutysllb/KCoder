# KCoder v0.6.16

> 发布日期：2026-09-23 · 上游基线：deepseek-harness **0.1.7-rc.1** (46a7f68b09)

## 新特性

- **上游基线跨入 0.1.7 系列**（0.1.6-alpha.2 → **0.1.7-rc.1**，经 alpha.1 / alpha.2 / rc.1 三段逐版核实后落地）。本版把 KCoder 的品牌化、桌面壳适配与五个内置插件全部迁到新契约上，随包运行的是一整套自洽的 0.1.7-rc.1 运行时。
- **内置浏览器放开**（设置 → 插件里的 `ui-sidebar-browser`）：上游该行按 profile 名判定（非 desktop 即关），KCoder 的 profile 名是 `web` 会被误关；产品策略层以同 id 行覆盖放开，桌面壳同时打开 `webviewTag` 并加固 guest。侧边栏可直接开网页并在应用内浏览。
- **工作步骤展示改为四档**（上游 rc.1 变更，随基线带入）：简洁 / **标准** / 详细 / 完全展开，并显示工具「准备中」阶段进度、思考与工具过程可折叠。

## 修复

- **内置插件随 0.1.7-rc.1 适配**（随包物化终态）：`dsh-coding-sidebar` **1.0.32**、`dsh-file-review-kcoder` **1.0.10**、`@kkutysllb/dsh-terminal` **1.1.1**、`dsh-skills-bundle` **1.0.2**、`dsh-shell-prefs` **1.0.1**。
- **侧边栏「任务管理」页恒显「加载中…」**（本版重点修复）：0.1.7 移除了插件读取的两个数据缝（子代理目录 `subagentsByParent`、作业名册 `jobsBySession`），而调用点是可选链、缺失即静默 no-op，于是整棵子代理拓扑被渲染成一列禁用的「加载中」占位行且永不恢复、控制台零报错。现按新契约改读 **逐 Session 投影**（`projectionsBySession[].values.subagentCatalog`）与 **`ctx.jobs` 客户端服务**（按会话 `watchRows`），未展开的目录分支用 `refreshProjections()` 显式读取。实测：36 个子智能体从「36 行加载中」恢复为真实条目（含标签、模式与运行态）。
- **会话页头「孤立横线」**：0.1.7 把页头拆成两层后，原先按 `> _titleRow` 直接子级锚定的收纳规则失效，页头容器带着 76px 最小高与一条底边线活了下来——表现为「会话一开始跑就冒出一条横线」。改为按 `data-slot="conversation.session.header"` 重锚，并新增 `scripts/smoke-workspace-header.mjs` 钉住（含判别力自检：旧锚点版本必须 FAIL）。
- **回合运行态的 KCoder 蓝色扫光回归**：0.1.7 的过程行改为裸 span 标签、同屏组标题用的是灰色微光，0.1.6 的深蓝渐变扫光丢失。现按 0.1.6 逐字复刻渐变与扫光，并以 `data-turn-running` 属性钩住运行态（文案是本地化的，状态只能走属性）。
- **内置插件运行时停用/卸载不再泄漏资源**（`dsh-coding-sidebar` 1.0.26 起延续）：sidechat 活跃线程、桥与 Wired 守卫、`systemPrompt.section` 段落随 `ctx.effect` 释放。

## 升级注意

- **「完全展开」这一档换了所指**（上游 rc.1 的模式重构）：档位由三档变四档——旧「详细」现叫**标准**、旧「完全展开」现叫**详细**，而界面上的**「完全展开」是新增的更展开档**。你此前的选择会被自动重映射（旧 `expanded` → 新 `detailed`），**观感不变**，不必手动改。默认档由「简洁」变为「标准」，未设置过的用户会看到更多细节。
- **运行中的过程组不再可折叠**：这是上游设计（仅 `标准`/`详细` 档保留历史轮次的可折叠组标题），不是回归。
- **首次启动会做一次会话日志 V4 迁移**（懒迁移，按需转换，不阻塞启动）；旧 `settings.yaml` 只会被尝试导入一次。
- **新增插件兼容性检查**：引擎在安装与启动时会校验插件的 DSH peer 版本范围，不满足即**停用该插件行**（只往 stderr 打一行，界面无感）。五个内置插件均已实测通过；**若你自己装了第三方插件，升级后若发现某个插件「消失」，请先看侧车 stderr 的 `disabling profile plugin` 行**，并按提示针对确切版本授予例外。
- **后台任务的唤醒次数不再设上限**（上游行为，KCoder 不覆盖）：修好了「连续后台任务后会话停住」，代价是引擎自带的防自激链被移除。若遇到后台任务自我唤醒形成长链，给对应会话显式配置该上限即可。
- **内置插件版本与预置声明**：随包物化终态为 coding-sidebar **1.0.32** / file-review **1.0.10** / terminal **1.1.1** / skills-bundle **1.0.2** / shell-prefs **1.0.1**。预置声明（`PRESET_PLUGINS`）按仓库约定使用**已发布**的版本并与物化同线：本版由 `^1.0.26` / `^1.0.7` 平移至 **`^1.0.32` / `^1.0.10`**，消除「声明旧版 + 实体新版」的窗口期。发布核验：两个版本在 **npmjs 均已可见且 `dist-tags.latest` 已指向**；npmmirror 对 file-review 已同步，对 coding-sidebar（57MB+，含 Univer/office 分包）**镜像同步滞后**，发版时仍在追赶——该源可见性不影响本版产物（随包实体由 `bundle/` 物化决定），镜像追平后即双源一致。
