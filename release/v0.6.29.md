# KCoder v0.6.29

> 发布日期：2026-10-10 · 上游基线：deepseek-harness **0.2.1-alpha.2**（`d7432673`）+ fork 集成分支 `kcoder/0.2.1-alpha.2`（`41f151ab20`）——引擎基线不变，本版是 **v0.6.28 现场回归的修复版**：四处打包态缺陷 + 两处「用户自装插件被静默清除」

## 修复

### 打包态才显形的四处

- **右栏终端 `终端错误：posix_spawn failed: Permission denied`**（macOS / Linux 打包版）：随包运行时的 tar 归档把头里的文件权限写死成 `0644`，`node-pty` 的 `spawn-helper`（必须 0755）因此丢掉执行位。修复：权限取自源文件，并新增**归档回读自检**（写完后复读 tar 头，逐条核对「源文件可执行 ⇒ 归档项必须带执行位」，不符即拒绝出包）。
- **实验性插件页「持久终端」组件异常：`a PTY backend named "shell" is already registered`**：上游 terminal-bundle 的 `optional-terminal-bash` 与 `optional-terminal-pwsh` 是同一个包的两个 entry（按平台互斥），插件页可以把「对手平台」那个打开，引擎写下显式 `disabled: false` 压过平台条件。修复：宿主启动期按平台**归一**对手 entry（幂等、只改该键）。
- **Codex / Claude Code 子智能体报 `requires its complete workspace checkout`**：这两个是上游的**按需安装**官方 bundle，而上游安装器只看运行安装锚点的清单——我们随包 runtime 的锚点清单是**工作树形态**（89 个依赖里 71 个 `workspace:`），于是被判成「源码检出」。修复：归档前把锚点清单归一为**已发布安装形态**，引擎随即走 registry 安装。
- 工具链：两处冒烟补 `@shared` 别名（主进程开始 import `@shared/...` 后，冒烟解析器缺别名会红）。

### 用户自装插件被静默清除（本版收口）

- **现象**：`@kkutysllb/dsh-git-panel` 装好可用，**每次重启后消失、需重装**；进一步排查发现同类还有 `dsh-context`（上下文）、`dsh-coding-sidebar`（侧边栏）、`@kkutysllb/dsh-terminal`（终端）等。
- **根因**：内置插件的**退役名单**（`RETIRED_PLUGINS` / `RETIRED_PRESETS`）在**每次启动**都执行「依赖声明 + 层叠 + 实体」三清；而名单里同时存在**npm 上仍可安装的现行名**。退役的原意是「我方不再随包提供」，却被实现成「禁止用户自行安装」。
- **修复（三条一起）**：① `@kkutysllb/dsh-git-panel` 从名单移除（它 2026-09-14 的退役理由——「右侧栏 Git 面板已覆盖」——已随 2026-10-09 右侧栏整线退役而失效）；② 凡 **npm 上仍可安装**的名字一律移出名单（`dsh-context` / `dsh-coding-sidebar` / `@kkutysllb/dsh-terminal` / `dsh-terminal` / `dsh-vision-router` / `dsh-better-sidebar` / `@tt-a1i/archify-dsh` / `@deepseek-ai/dsh-experimental-schedule-bundle`），并写下判据：**退役只影响我方是否随包提供，不得禁止用户自行安装**；③ 名单只保留 npm 上已不存在的纯残留名，并改为**一次性清理**（账本 `$DSH_HOME/.retired-cleaned.json` 记账，清了就不再碰）。
- **顺带**：孤儿判据改保守——**实体在位绝不判孤儿**，用户插件即便声明丢失也不会被删实体。

## 验证

- 隔离复现（真启动函数 + 临时 `DSH_HOME` + 全新账本）：装好 `dsh-context` / `dsh-coding-sidebar` / `@kkutysllb/dsh-terminal` 后跑启动链 ⇒ **三者全部存活（首次即通过，无需预热）**。
- 归档自检、平台互斥归一、孤儿判据、退役账本各有断言与**负对照**（去掉判据即红）。
- 仓库聚合门 `pnpm check` **39/39**（含 shell 协议 65 断言、注入面自检、版本线、profile 自愈 39 项）。

## 升级注意

- **你此前自装、后来「消失」的插件，升级后重装一次即可长期保留**（本次修复后不会再被清）。
- 自装 `dsh-coding-sidebar` 会与上游原生右侧栏并存（两边各有一套）——这是你的选择，产品不再阻止。
- 随包 vendor 的 pnpm 由 `11.7.0` 提升到上游声明的 `11.28.5`（同主版本 11.x，无迁移动作）。
- 工作台仍为协议化加载唯一形态（v0.6.28 起）。无需其它手动迁移，重启应用即生效。
