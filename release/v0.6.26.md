# KCoder v0.6.26

> 发布日期：2026-10-08 · 上游基线：deepseek-harness **0.2.1-alpha.1**（`5badb15009`）+ fork 集成分支 kcoder/0.2.1-alpha.1（`161c7122f6`）——引擎基线**不变**，本版是**独立桌面端改造的收口**：工作台加载协议化转正、技能面归原生设置页、landing 重设计

## 新特性

- **工作台加载协议化转正：`127.0.0.1:端口` 从页面视野里消失。** 此前工作台一直加载 `http://127.0.0.1:<随机端口>/?token=…`——引擎侧车的回环地址直接暴露在页面 origin、开发者工具和历史记录里。现在自定义协议 `kcoder-app://app` 接管页面供给：文档与 API 照常转发给本地引擎（上游服务端注入表原样生效），页面 origin 恒定可读，WebSocket 由主进程守卫改写头后直连侧车（只放行本应用窗口），登录 cookie 只活在主进程、不再落进页面可见的任何位置。

  与上游官方桌面壳**同构而形态不同**：上游把渲染层打包成磁盘 dist、用 preload 递注入；本产品照旧转发引擎实时渲染的文档（服务端注入表不破），只注入一个全局变量 `__DSH_TRANSPORT__.streamBaseUrl`——**壳保持无 preload**，这是本产品自持窗口几何的前提（铁律 1）。设置页新增「工作台协议加载」开关，灰度期内随时可切回旧直连形态；诊断页会显示当前加载形态。

- **技能管理归原生设置页（`dsh-skills-bundle` 1.1.0）。** 插件 1.1.0 自带「技能 / 可选技能」两个原生设置分区与自有持久化。本产品早前自建的「技能」设置分区与之并存即冲突（两套注入器抢同一锚点），整链退役：注入器、目录扫描、连带的工作区探针上行链、专属冒烟全部拆除。技能的启停从此只在上游原生分区里管理，一处说清。

- **Landing 页重设计：真实桌面截图 + 卡片布局 + 恒深色。** 参考 deepseek.com/harness 的版式重做首屏：居中 hero（眉题 / 双行标题 / pill CTA）→ 真实运行态抓取的桌面大图（工作台 / 内置终端 / 侧边工作台三张特性卡片，外层 CSS 绘制 macOS 窗壳）→ 渐显交错、呼吸光晕、hover 抬升等纯 CSS 动画（系统开了「减弱动态效果」时全部退场）。**主题切换退役，landing 恒深色**；进入工作台后界面主题仍跟随上游渲染主题。

- **内置侧边栏 1.0.40：做减法。** 移除「智能体团队 / 侧边对话」页签与「按功能启停」开关——能力全部内置开启，旧的启停配置键不迁移。本产品消费面零适配（页签唤起与几何契约未动）。

## 修复

- **诊断日志里的引擎地址不再泄漏令牌。** 协议化加载后诊断里仍有一行 `dsh web: http://127.0.0.1:…/?token=…` 明文令牌（用户实测发现）。现在日志写入时令牌一律打码为 `***`。

- **MCP 服务器设置页对齐技能分区的设计语言。** 网格卡片布局、胶囊启停开关（品牌 seal-fill）、`color-mix` 主题自适应描边、两行截断的命令摘要——与新版技能分区同一套视觉语言，深浅色都成立。

- **修掉三处「Windows 上永远修不好的假失败」+ 一处空头支票快捷键**（Windows 环境实测回传）：
  1. 依赖新鲜度自检逐字节比较锁文件快照，而 Git 在 Windows 把工作树检出成 CRLF、pnpm 写的快照恒为 LF ⇒ **每次启动都误报「依赖陈旧」且按提示重装永远修不好**。改为归一化行尾再比。
  2. 内置插件同步对账的文件比较是同一类陷阱（真源 CRLF、镜像 LF），同法归一化。
  3. profile 自愈冒烟用「临时目录不在主目录里」判隔离生效，而 Windows 的 TEMP 就在主目录里 ⇒ 判据恒假、聚合门永远 24/25。改为只认真主目录的三个已知落点。
  4. Landing 的「⌘ ↵」既是硬编码 Mac 字形、又**根本没有绑定按键**（任何平台都按不响）。现按平台显示 `⌘ ↵` / `Ctrl ↵` 并兑现快捷键（与「进入工作台」同一代码路径）。

- **「在本地编辑器中打开」状态栏按钮退役。** 其背后的 open-in-app 注入器一并下线（协议化加载后该旁路无存在意义）。

- **麒麟换锚遗留清理。** 麒麟引擎可行性分析文档作废并删除（结论：等麒麟 3.1.x 后再对齐），麒麟时代的 staging 残留树清除。

## 升级注意

- **Landing 没有浅色主题了**：首屏恒深色，主题切换入口退役；进入工作台后的明暗仍跟随上游界面主题，不受影响。
- **自建「技能」设置分区消失**：技能启停改在原生「设置 → 技能 / 可选技能」里管理（插件自有持久化）；此前若用自建分区调整过技能目录，请在原生分区重新确认。
- **侧边栏「按功能启停」的旧配置键不迁移**：1.0.40 起能力全部内置开启。
- **「工作台协议加载」开关**（设置页）保留：协议化加载遇到问题时可切回旧直连形态并重启引擎即恢复；观察期结束后该开关与直连路径将按计划退役。
- 无需手动迁移；重启应用（或托盘「重启引擎」）即生效。
