# KCoder v0.6.11

> 发布日期：2026-09-12 · 上游基线：deepseek-harness 0.1.5-rc.2 (fb2c4b9e)，集成分支 kcoder/0.1.5-rc.2（尖端 1fc823f08d）

## 修复

- **Windows 标题栏深浅反转（0.6.1 遗留）**：点击深色主题右上角按钮区变浅、点浅变深。根因是偏好上报与乐观更新的赛跑——页面主题按钮先翻 DOM、后异步持久化偏好；主题观察脚本在 DOM 变化瞬间上报实色（正确）后立刻 fetch 首页解析偏好档，该请求跑在持久化落盘之前读到**上一档**，主进程偏好档分支里 `applyShellChromeTheme(win, 旧值)` 随即把刚画对的 overlay 打回——形成稳定反转。两层修复：
  1. **页面一致性门**：解析出的偏好档必须与当前实色自洽（`system` 恒自洽），不一致即判定读到持久化前的旧值，延迟 500ms 重读（最多 3 次）后再上报，绝不发布自相矛盾的偏好；
  2. **chrome 与偏好解耦**：主进程偏好档分支只驱动 `nativeTheme`（三态/跟随系统语义），窗口 chrome（背景色 + Windows overlay）一律跟随实色通道（DOM 权威）；跟随系统档的系统翻转由 `nativeTheme 'updated'` 重同步兜底。选「跟随系统」读到过期 system 时走 `shouldUseDarkColors` 打翻 overlay 的次生路径一并消除。

## 升级注意

- 无迁移、无配置变化；v0.6.1 的引擎侧修复（Windows 沙箱链黑窗 CREATE_NO_WINDOW + windowsHide）原样延续。
