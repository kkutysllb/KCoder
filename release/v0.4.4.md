# KCoder v0.4.4

> 发布日期：2026-08-30 · 上游基线：deepseek-harness 0.1.2-alpha.1 (cd5ef814)

## 新特性

- **上游基线升级至 0.1.2-alpha.1**：新会话架构（增量快照 / timeline 全量索引），并以此接入交付文件审查能力；上游锚定切换至自有 fork（kkutysllb/deepseek-harness），修复以提交直接落集成分支
- **宿主面板全面插件化**：Git 面板（@kcoder/git-panel）、内嵌终端（@kcoder/terminal）、文件审查（@kcoder/file-review）收编为内置 bundle，壳层宿主实现退役，随应用一体物化分发
- **品牌界面微调**：Windows 标题栏左角装饰红绿灯替代重复的 K logo；设置-关于增加 logo、移除开发者信息
- 流镜（flowglass）经内置化试验后撤销收编：改为退役插件自愈清理，旧安装升级时自动移除

## 修复

- **交付卡片统计当场归零**：任务完成时交付卡片行统计显示 +0 -0（展开与重启后正常）——修复 inject 结果被会话级缓存导致的冻结快照问题，并补齐冷启动时服务未就绪的自愈路径，统计实时随任务更新
- 附件插件适配新基线 contenteditable 输入框：修复发送事务漏 return 导致的输入框锁死、以及 Everything 可执行文件缺失引发的进程崩溃
- 启动自动清理堆积的认证 cookie，消除请求头超限（431）导致的登录态异常
- 内置物化门健壮性：按各包 entry 字段判定产物存在性，自愈清理 profile 依赖声明残留

## 升级注意

- 本次为基线大版本升级（0.1.1-rc.2 → 0.1.2-alpha.1），第三方插件如无法加载，请确认其已适配新版 keyed slot 注册契约
