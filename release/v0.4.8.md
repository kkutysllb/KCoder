# KCoder v0.4.8

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.2-alpha.2 (0a53fb5)

## 变更

- **上游基线升级 0.1.2-alpha.1 → 0.1.2-alpha.2**（234 提交）。上游新能力随基线进入：界面显示连接异常状态并支持自动重连/立即重连；会话标题区域可查看活动的定时计划；设置页插件列表按会话插件和全局插件分组，可切换 Agent Preset 查看组合并搜索其它预设；回答末尾显示 token 用量和耗时（点击查看详细统计）；恢复 0.1.2-alpha.1 中移除的 SessionEvent.ignorable；改善会话与输入界面的菜单显示、滚动条、工具文件链接与 diff 统计；修复 Node.js 24.0–24.11.1 上启动可能失败且 HMR 失效的问题；减少 macOS 和 Linux 加载会话时不必要的文件系统检查；提升长会话历史和密集实时消息的处理效率
- **收编插件 dsh-better-sidebar 适配新基线**：alpha.2 移除了 settings namespace 工厂导出（register 直接收字符串），上游 0.17.1 在新基线上加载即崩；自有真源 dsh-plugins/DSH-better-sidebar 发布 0.17.2 完成适配，profile 消费源从上游 github 仓切换到自有 monorepo 子目录引用（git+ssh），后续版本随真源仓迭代
- **注入锚点全面核对**：新基线上 KCoder 全部注入锚点（设置页 slot 契约、会话服务面、sendSession 签名、插件路由契约、composer 骨架特征）逐项核对零破坏，第三方插件锁版继续有效

## 升级注意

- 无需手动操作：预置与自装插件随 profile 自愈机制自动迁移；dsh-better-sidebar 由旧上游版本到自有 0.17.2 的切换在 profile 依赖刷新时自动完成
