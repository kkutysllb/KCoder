# KCoder v0.6.19

> 发布日期：（待发布） · 上游基线：deepseek-harness **0.2.0-rc.1** (4878cdabd8) + fork 集成分支 4cbc050f

## 上游基线跨入 0.2 系列

从 0.1.7-rc.2（477b4f4205）升级到 **0.2.0-rc.1**（4878cdabd8）：261 提交 / 1109 文件。逐项核实后落地——差异分析见 `docs/upstream-0.2.0-rc.1-analysis.md`（29 条发布说明逐条代码落点 + 未提及变更盘点），执行记录见 `docs/upstream-0.2.0-rc.1-upgrade-plan.md §20`。

## 升级注意（用户可见变化）

- **定时任务与时间上下文改为可选组件**：上游把这三行从默认组合抽成独立可选包 `@deepseek-ai/dsh-experimental-schedule-bundle`，KCoder 已内置选中，开箱即用不变；现在也可以在「设置 → 插件」里自行开关。
- **侧边栏（dsh-coding-sidebar）与改动审查（dsh-file-review-kcoder）升级**到兼容 0.2 引擎的版本（1.0.35 / 1.0.11）。旧版本在新引擎上会被静默禁用（侧边栏整片消失），本版随包携带修复。
- **会话日志上传保持关闭**，产品策略未变；上游新增的「上传 Session Log」设置开关已按策略隐藏（该开关在本产品策略层下无法生效，隐藏以免误导）。
- **桌面遥测显式关闭**：不再依赖上游按 profile 名的默认判定，两行遥测插件显式禁用。
- 若之前手动关过定时任务，升级后设置会重置为开启（启用机制从配置覆写改为组件选中）。

## 新特性（承接上游）

- 任务计划**递归扫描次级目录**（KCoder 自研增强）：`plans/`、`docs/plans/`、`.plans/` 下的子目录现在会被递归收录（最深 6 层，跳过 `node_modules`，不跟随符号链接）——按主题或版本分层存放的计划不再缺席「任务计划」页。
- 对话运行态动画与过程信息优化（上游 0.2：鲸尾动画、统一微光、过程行间距收紧）。
- 插件管理界面与安装引导改进（上游 0.2）。
- Office / PDF 预览文字选区在浅色、深色主题下更清晰（上游 0.2）。
- 使用 DeepSeek 账号模型的会话无需配置额外 API Key 即可进行网页搜索（上游 0.2）。
- 工具调度异常后对话可继续；结果未知的操作会提示先核实副作用，不盲目重试（上游 0.2 内核修复）。
- Windows 沙箱新增权限诊断技能（上游 0.2）。

## 修复

- 修复 Safari（WebKit）在回答输出中刷新页面后无法恢复回复的问题（上游 0.2）。
- 修复 Windows「在文件资源管理器中打开」可能打开隐藏窗口的问题（上游 0.2）。
- 修复 macOS 桌面端缺少录音权限的问题（上游 0.2）。
- 修复部分 Linux 环境缺少可选原生预构建包时的安装失败（上游 0.2，Koffi 精确钉版）。
- 远端工作区：4 个 SSH 运行时包随引擎同线升级到 0.2.0-rc.1。

## 已知变化 / 取舍

- 运行指示动画从自研复原的深蓝扫光改为上游原生 TextShimmer 微光（上游已原生提供同能力，自研层随之撤销；实测运行态文案品牌化不受影响）。
- 本版插件 peer 口径采用双兼容范围 `>=0.1.7-rc.2 <1.0.0`（同时覆盖旧引擎与新引擎的 rc/正式版），计划在下一轮插件发版收窄为 0.2 线。

## 已知问题（与本版升级无关的既有项，登记备查）

- `smoke-panel-buttons` 冒烟失败：标题栏第四枚按钮的平移规则从未写入 `SHIFT_JS`（v0.4.6 起如此）。
- `smoke-skills-dom` / `smoke-skills-page` 冒烟挂起：构建期插值常量与冒烟提取方式不匹配（v0.5.9 起如此）。
- `dsh-context` 预置插件版本漂移（0.59.2 vs 补丁键 0.55.0）：补丁链待重出，不影响本版功能。
