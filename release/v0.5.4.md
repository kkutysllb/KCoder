# KCoder v0.5.4

> 发布日期：2026-09-03 · 上游基线：deepseek-harness 0.1.2-rc.1 (a66e4702)

## 修复

- **设置页导航图标区分**：设置对话框左侧导航中，「技能」「MCP 服务器」「关于」此前与「通用设置」共用同一个齿轮图标，一眼难辨；现分别换为技能（文档 + 闪光）、链环（连接）、问号圈（信息）三个专属图标，path 数据零误差取自上游原生图标库，与「模型 / 插件 / Agent 预设」的图标体系同源，深浅主题跟随。

## 内部维护

- 上游基线升级 0.1.2-alpha.4 → 0.1.2-rc.1（0.1.2 首个候选版）：
  - 投影缓存读兼容：引擎可直接读取旧版本（v3/v4）缓存条目，条目身份缺字段按未播种谱系处理——与 v0.5.3 的启动迁移互为双保险，未迁移场景由引擎兜底；
  - 坏档自救：单份缓存文档损坏时自动备份隔离（`.bak.<时间戳>`）并按未缓存处理，不再拖累其他条目与整体读取；
  - 本次上游实质变更仅投影缓存 / 存储层 8 个文件，事件层与 UI 零变更；注入锚点零触碰。

## 升级注意

- 无需手动操作：v0.5.3 已完成的缓存迁移继续有效，rc.1 引擎读兼容自动兜底。
