# KCoder v0.6.15

> 发布日期：2026-09-20 · 上游基线：deepseek-harness 0.1.6-alpha.2 (ddefc45fbc)

## 修复

- **侧边栏收起后账号菜单点不开**：收起态下上游设置触发行的空外壳（36×36、定位元素、DOM 排在账号行之后）与头像圈同格同位，外观照旧、点击却被它吃掉。头像圈补 `z-index` 压过同层定位兄弟；展开态不受影响。新增 `scripts/smoke-account-chip.mjs` 钉住这条（含命中归属断言，去掉修复即红）。
- **`pnpm dev` / `pnpm start` 在桌面端派生的终端里必崩**：环境继承的 `ELECTRON_RUN_AS_NODE=1` 会让 electron 以纯 Node 模式启动（`electron.app` 为 undefined，主进程首个 `app.getVersion()` 即 TypeError: reading 'getVersion'）。dev 包装启动前自动剥离该变量并打印一行提示（`dev` / `start` / `build` / `preview` 全覆盖）。
- **内置插件随上游 0.1.6-alpha.2 适配**（随包物化终态）：coding-sidebar **1.0.26**、file-review **1.0.7**、terminal **1.1.1**、skills-bundle **1.0.2**、shell-prefs **1.0.1**——运行时停用/卸载不再泄漏资源（sidechat 线程、桥与 Wired 守卫、system prompt 段落），`node-pty` 补声明依赖，QiLin 双通道键位补齐。

## 调整

- **「桌面样式定制」整组下线**（设置 → 通用）：正文密度 / 正文字号 / 消息列宽 / 总开关四张卡移除，正文排版回到上游原版（16px 正文、748px 消息列），轨迹页与「跳到底部」按钮也不再由宿主改造。**空会话的 K 水印保留**，且不再受任何开关影响（它是品牌落点，不是排版偏好）。
- **标题栏按钮顺序**（红绿灯右侧）：改为 **上一个会话 / 下一个会话 / 折叠侧边栏**。两枚导航箭头是一对耦合控件（同 Finder/Mail 的返回-前进序），折叠按钮改的是布局，落在它们右侧。
- **菜单瘦身**：应用菜单「工具」与托盘菜单移除「设置（上游初始化）」「同步上游仓库」两项。上游未就绪时初始化面板照旧自动弹出；手动同步走「设置（上游初始化）」页的按钮或终端 `pnpm sync-upstream`。
- **预置插件声明与内置物化同线**：`dsh-coding-sidebar ^1.0.26`、`dsh-file-review-kcoder ^1.0.7`（两版均已发布且 npmjs/npmmirror 双源可见），新装 profile 的依赖树解析直取同版本，消除「声明旧版 + 实体新版」窗口期。

## 升级注意

- 若你此前把「桌面样式定制」调成过非默认档（紧凑密度 / 自定义字号 / 加宽列宽），升级后这些偏好不再生效（配置项已移除，旧设置文件里的残留键不参与任何判定），排版统一回到上游原版——这是本版的预期行为。
- 退出登录、语言、主题三个入口不变：仍在侧边栏底部账号头像的菜单里。
