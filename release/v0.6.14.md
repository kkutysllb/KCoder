# KCoder v0.6.14

> 发布日期：2026-09-19 · 上游基线：deepseek-harness 0.1.6-alpha.2 (ddefc45fbc)，集成分支 kcoder/0.1.6-alpha.2（尖端 a01f995e87）

## 基线升级（0.1.6-alpha.1 0a15e36e7f → 0.1.6-alpha.2 ddefc45fbc）

887 提交 / 2622 文件（2 天窗口，代码面约 2270）。契约层逐项核对结论：`SESSION_FORMAT_VERSION` 仍为 **3**（无会话迁移）；`ui-slots` 导出零删除；`--patch` / `--no-open` / 就绪行 / DOM·CSS 锚点、产品 overlay 的目标行 id 全部存活；第三方插件 peer 键按 npm 预发布规则直接覆盖 alpha.2，无需改动。

**本版最硬的升级阻断：Electron 39 → 44.0.0。** alpha.2 起 profile 解析默认模式由 `link` 切到 `runtime`，其原生 addon 按 **V8 指纹精确匹配**内嵌凭据表取 `internal/modules/esm/loader`；Electron 39 不在表内、且调用点无 try/catch 又在 boot 路径上 → **引擎根本起不来**（此前一直"能跑"是因为运行时解析优先用随包的旧引擎）。钉精确 `44.0.0`（凭据表登记值），`node-pty` 已按该 ABI 重编。

## 随基线启用的能力（用户可见）

- **插件管理器新体系**：安装 / 卸载 / 启停 / 重试 bundle，按包聚合 manifest 与活树为单一视图；pnpm 安装输出流式呈现；可取消；外部 bundle 隔离成 contained-group——**单个 bundle 挂载失败不再拖垮整个 Loader**，只记入 `pluginFailures`。
- **交付物体系（第二重主题）**：Host 侧按 turn 记录文件变更的 git 快照；changed-files 卡片渲染真实变更、**卡片内逐文件 diff**、单 tab 评审一个 turn 的全部变更文件。
- **归档会话恢复**：设置页「已归档会话」分区，归档后可一键恢复。
- **客户端体验**：composer 用 Enter/Tab/Escape 接受或离开模型、上下文用量移入 composer 统计、文件引用冒号标签；plan 提交后保留在对话中且卡片自动打开；工作区树可按父文件夹分组；PDF 与终端运行时懒加载。
- **模型目录收缩**：缺省目录只剩 `deepseek-flash`（默认模型不变）与 `deepseek-v4-pro`；被移除的 id 显式配置时仍按 text-only 路由透传（模型选择列表会变短，属上游设计）。
- **引擎侧**：子代理委托限额后端化（限额由后端持有、可在插件设置页编辑）；MCP 层零变化——上一版的启动提速修复原样适用。

## 产品与适配（KCoder 侧）

- **自研侧边栏插件回归，并成为唯一侧栏**：内置镜像 `dsh-coding-sidebar` → **1.0.21**（turnTail 槽位 `chain→list` 适配、当前会话推导修复、文件打开门延迟装配、安装期诊断）、`dsh-file-review-kcoder` → **1.0.5**（alpha.2 严格 codec 契约适配 + 增强评审卡）。原生右侧栏的服务层与契约保留（主对话链硬依赖），**用户可见外壳压制**；侧栏开关由标题栏右端按钮代理转发插件自己的开关。
- **打开动作全部落进插件**：消息里的文件链接 / 交付卡 / `@` 引用 / `/技能` 引用一律在插件侧栏的编辑器里预览，不再落到原生面板。
- **新增「在本地编辑器中打开」按钮**（标题栏第四枚）：默认图标用你的应用身份——记忆上次选择的应用 → 否则菜单中第一个编辑器 → 再否则通用代码字形。
- **状态栏徽章链三处断裂全修**：① 主进程改用签名 cookie 调 `/api`（此前裸 fetch 一律 401，历史补拉静默失败）；② 分页游标改用 `projections.asOfSeq`（alpha.2 下 `throughSeq=-1` 返回空页）；③ PTC 模式改消费 `workspace/changes` 的 git numstat——**PTC 模式现在也有 +N/−N**，且与工具参数近似值同池聚合时精确值优先。新增 turn-end 探针：任务跑完约 3 秒内徽章落地，不必再翻页触发。
- **+N/−N 改为绿增红删**：工具卡折叠行与展开后的 diff 合计两处同时着色（用上游自己的 success/error token，不新造色）。
- **账号菜单增加「语言」「主题」**：经新增内置 bundle `dsh-shell-prefs` 走上游唯一写入口（与设置页同一条路径，无第二事实源）；选中后菜单不关、对勾当场移动、可连续切换；点菜单外或点设置正常关闭/进入。
- **源码态与打包态实例隔离**：dev 用 `…/KCoder-dev` 与 `~/.kcoder-dev`，**两态可同时运行、互不干扰**（此前因单实例锁同键与 DSH_HOME 同目录结构性互斥）。
- **启动与稳健性**：内置 MCP 服务器全部钉精确版本 + 离线优先（消除每次启动的在线 latest 解析，网络抖动不再拖住 boot）；profile 畸形态自愈（清孤儿 bundles 注册、卸载按注册形态选路）；「设置 → 插件」的两个 tab（只读清单 + 插件管理）与卡片可点。
- **运行时交付链止血**：签名不再依赖 Apple 时间戳服务（已合规签名跳过 + 退避重试）、`flatten` 对可解析链接落实体并对嵌套链接下探 + 归档前最终 sweep——此前三处缺陷会让**归档静默停留在上一次发版的旧件而发布照常继续**。
- **退役**：沙箱重复审批的下游热修整链移除（上游 `61c548e200` 已含在 alpha.2 内，补丁成死代码）。Windows 黑窗修复保留——那是**引擎进程自身**的 spawn，与上游 subprocess 层修复互补不重叠。
- **产品策略层（`dsh web --patch`）三行**：会话日志不上传（上游默认会把完整未接受会话日志随请求上报，KCoder 显式关闭）；原生终端整行禁用（终端走内置 `@kkutysllb/dsh-terminal`）；原生 changed-files 尾卡关闭（只关尾卡、保留全部数据面），由 file-review 增强卡接管。

## 产品铁律（本次定档，随本版入库）

> 记入 `docs/ARCHITECTURE.md` §12，效力高于单次升级的便利：

1. **不使用上游原生侧边栏功能**——右侧工作台只由自研 `dsh-coding-sidebar` 承担；上游每次改动侧栏契约，处置路径是**改插件仓并发新版本**，不是把原生接回来。
2. **新版本适配只改插件源码**——KCoder 只做消费接线（BUNDLES / PRESET_PLUGINS / sync-bundles 映射）、宿主侧产品压制、本仓自有功能；宿主自身契约（就绪行 / CLI / DSH_HOME / 注入锚点 / Electron ABI）的适配仍在本仓。

## 本版未启用 / 已由内置实现替代的上游能力

> 上游 0.1.6 发行说明包含以下能力，但在 KCoder 默认组合中**不可用或走的是另一条实现**，列此避免误解：

**已由内置实现替代（上游那套在 KCoder 不可见）**

- 上游**侧栏浏览器**（消息里的 HTTP(S) 链接默认进侧栏 browser tab）——按铁律 1 不使用，链接回落既有行为。
- 上游**原生右侧栏**的文件树 / 文档预览 / 终端 tab——外壳已压制；预览与终端由内置侧边栏与内置终端承担。
- 上游**插件管理面板**在侧栏的入口——管理面在「设置 → 插件」（含只读清单与插件管理两个 tab）。
- 原生**终端**入口与原生 **changed-files 尾卡**——见上「产品策略层」。

**默认不挂载（需显式启用）**

- 实验性 Auto review、Browser Use（Playwright / Chrome DevTools / Stagehand）、Computer Use、SSH 远端工作区、Headless 运行。

**不属于本产品交付物**

- 上游自带 Electron 桌面链（`apps/desktop`，独立 appId 与产物）——与 KCoder 打包链目标重合但不同物，本版无冲突；中期再评估复用其 runtime 物化器。

## 升级注意

- **无数据迁移**：`SESSION_FORMAT_VERSION` 仍为 3，旧会话直接可读。
- **首次启动**：引擎运行时为 0.1.6-alpha.2；**安装版 0.6.13 上的 PTC「sandbox initialization failed: Operation not permitted」随之消失**（根因是旧引擎未豁免 `ELECTRON_RUN_AS_NODE`，上游 `a66d81e33f` 已修，本版运行时含该修复）。
- **界面变化**（均为预期）：原生右侧栏入口消失、原生终端入口消失、插件管理在设置页、模型选择列表变短。
- 内置插件随包内容只服务全新安装；已安装用户经「设置 → 插件」独立升级插件。
- 打包：macOS 打包与公证需 `APPLE_ID` / `APPLE_APP_SPECIFIC_PASSWORD` / `APPLE_TEAM_ID`（CI secret）。
