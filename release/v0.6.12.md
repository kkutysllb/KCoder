# KCoder v0.6.12

> 发布日期：2026-09-14 · 上游基线：deepseek-harness 0.1.5-rc.2 (fb2c4b9e)，集成分支 kcoder/0.1.5-rc.2（尖端 1fc823f08d）

## 变更

- **退役内置 git 面板插件 dsh-git-panel**：侧边栏工作台（dsh-coding-sidebar）的 Git 面板已完整覆盖变更/暂存/提交/分支/worktree/历史操作（Git/会话双视角），内置 @kkutysllb/dsh-git-panel 能力被覆盖，整线退役三清——profile bundles 层叠残留摘除、deps 声明摘除、物化/安装实体删除，升级后首次启动自动完成。推送/GitHub 管理（gh PR/Issue）/比较外链后续由侧边栏版本承接；任务计划已定为侧边栏独立 tab 形态实现。
- **内置插件镜像刷新**（sync-bundles 对账归零）：dsh-coding-sidebar 1.0.6 → 1.0.12 线（agent 浏览实况自动切换边沿触发修复、上游修复线回流、终端等待 banner/文件树重命名删除、文件变动 Git/会话双视角、交付卡片让位与 openResource 接管、官方文件图标 + registerFileIcon、轨迹图 Tab）；dsh-file-review-kcoder 1.0.0 → 1.0.3。随包内容仅服务全新安装，已安装用户经插件管理页独立升级，不受本版影响。

## 升级注意

- 无迁移、无配置变化；首次启动自动清理 dsh-git-panel 残留（日志可见 `[kcoder-bundle] 清除 profile 退役插件残留`），标题栏「git 工作区」入口随之消失，git 操作统一走侧边栏 Git 面板。
- 内置插件独立升级线不变：插件管理页检测 npm 新版本、用户手动更新。

- typecheck 双 project 通过；全仓库审计三门 PASS（报告见 `release/audit-v0.6.12.md`）。
