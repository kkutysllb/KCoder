# KCoder v0.5.0

> 发布日期：待定 · 上游基线：deepseek-harness 0.1.2-alpha.1 (cd5ef814)

## 新特性

- **Git 面板对齐 Codex 浮动面板能力（@kcoder/git-panel 0.5.3）**：新增「环境信息」区——变更文件列表（逐文件状态码 + 行数，点击经 better-sidebar 预览）、工作位置子菜单（本地/linked worktree 只读切换）、分支选择器（搜索 + 当前分支✓ + 创建并检出新分支 + 分支删除：安全删未合并时升级强制删除确认）、提交或推送（有任何待提交变更即激活；无暂存时自动暂存全部变更再提交 + 按上游推送，含 N 待推送提示）、比较分支外链（按 origin 派生 GitHub compare URL 系统浏览器打开）、设置页联动（进设置页自动收起、返回工作区自动展开）；主题跟随修复：面板改挂 body 子树并移除 prefers-color-scheme 轨道，唯一对齐应用内主题标记，切主题即时生效；同步开源同步至 dsh-plugins 仓库（子目录 monorepo 布局）
- **会话统计面板插件化（@kcoder/stats-panel 0.1.0）**：输入框下方统计缩略条的 hover 图表面板从宿主注入（desktop/main/stats-hover.ts 已删除）抽为独立内置插件（纯 client 交付，entry 占位 + client 自绘面板，物化模式对齐 git-panel）；顺带修复新基线解析断裂——上游时长改走 i18n 文案（中文界面显示「45.2秒」「2分42秒」），旧正则只认英文格式致 LLM/工具调用/首 token 三项时长显示「—」，现 zh/en 双格式兼容；同步至 dsh-plugins 仓库
