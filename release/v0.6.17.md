# KCoder v0.6.17

> 发布日期：2026-09-25 · 上游基线：deepseek-harness **0.1.7-rc.2** (477b4f4205)

## 新特性

### 定时任务：内置、开箱可用

- **可以给会话排计划了**：让 Agent「每天早上 10 点抓一次财经热点」「两小时后提醒我」这类要求会落成一条**定时任务**，到点在**原会话**里注入提示继续跑。侧边栏新增**「自动化任务」**入口：全部 / 已开启 / 已结束三态筛选、搜索、逐条查看运行记录、改时间、删除、立即重试。
- **任务跨重启保留**，最短可每分钟重复一次；会话长期关闭期间错过的触发只补最近一次。
- **时间上下文同时启用**：模型因此能解析「明天九点」这类**未限定时间**的说法（它拿到当前时间、时区与已用时长）。
- **上游把这三项默认关掉了**（说明文案写「需要时可手动启用」，但**界面上并没有启用入口**——承载它们的 `@deepseek-ai/dsh-web-app` 被插件管理页按设计排除，官方路径是让 Agent 装一个覆盖用的工作包）。KCoder 直接在产品策略层放开，**开箱即用**。

### 任务详情落在自家侧边栏（不再弹原生右栏）

- 轮尾卡上的**「打开」**、以及会话头部的任务入口，现在一律把任务**预览卡**开进侧边栏插件的**「任务计划」页签**：标题、频率、下次触发、投递内容一览，可「收起」。
- **不再展开原生右侧栏**——那一列一展开就在主对话区旁留出一大片空白（同一个问题在「上下文」跳转上已于 0.6.16 处置过一次，这次把任务这条路径一并收口）。
- 数据面与导航面分离：引擎只传**身份**（会话 + 任务 id），任务内容由侧边栏插件自己读取，因此预览显示的是**当前**状态。

### 上游基线 0.1.7-rc.1 → 0.1.7-rc.2

- rc.2 是 0.1.7 系列**最大**的一个版本（224 个非合并提交 / 3429 个文件 / 约 24.6 小时），本版把品牌化、桌面壳适配与五个内置插件全部迁到新契约上，随包运行的是一整套自洽的 **0.1.7-rc.2** 运行时。
- 随基线带入的用户可见变化，重点三处：**工具描述瘦身**（标准档首轮提示约 −18%，同样内容更省 token）、**快捷键体系**（可查看 / 搜索 / 自定义 / 恢复，侧边栏同步显示键位）、**归档筛选三态**（隐藏已归档 / 全部 / 仅归档）。另有折叠网页抓取卡可直接点网址、审批卡片跟随界面语言、语法高亮支持更多文件类型、文档预览浅色主题与间距统一等一批体验优化。
- 升级复核（逐条实测）：**内置插件无需升版**（兼容性门禁全过）、**注入锚点全存活**、**数据缝零缺口**、构建与回归零新增失败。详见 `docs/upstream-0.1.7-rc.2-analysis.md`。

### 内置插件：热补丁发版闸

- 内置插件（如 `dsh-context`）的常驻修复补丁靠「pnpm patch + 版本无关的兜底注入」跨版本物化，任何一处断供都会让新装用户拿到**裸插件**。本版新增**发版闸**（`release.sh patchgate`，挂在 build / prepush / ship 前）：只读校验分发清单非空、实装产物修复特征全中、版本键零漂移、profile 声明就位——不过即中断发版。

### `dsh-context` 升级到 0.55.0

- 预置第三方插件跟随主线升到 **0.55.0**，随包携带两条常驻修复：
  - **Windows 打开「上下文」冻结白屏**（尺寸观察器回路冷却）；
  - **轮尾「在上下文视图中查看此轮」跳转不再展开原生右栏**，一律走会话内页签。

### 内置插件开发清单

- 新增 `docs/plugin-dev-checklist.md`：把「用实机测试换来」的跨层默认语义钉成清单（可选面只能走 `ctx.get` / `ctx.inject`、插件改动必须 bump 版本、`openTab` 要带 `meta` 才算内容型、预置声明只指向已发布版本），每条含**产物级判据命令**。

## 体验优化

- **原生右侧栏彻底不可用**（产品铁律 1 的执行点）：展开按钮、面板、整列与拖拽分隔条全部隐藏，任何路径都弹不出来；依赖它的上游插件仍正常挂载（只是那部分 UI 不再出现在 KCoder 里）。
- **中间对话区不再被挤窄**：右栏列不存在之后，长对话的正文宽度稳定，不会再出现「右边空出一大条」。
- **开发态与安装版可以同时开**：源码态的浏览器宿主端口与安装版分开（9224 / 9223），不再互相顶掉，也不会出现「开发态的 Agent 浏览其实连到了安装版的浏览器」。
- **标题栏避让配置真正生效**：新装用户的侧边栏面板顶部会正确为 KCoder 自绘状态栏让位（此前该配置写到了一个不存在的目标上，macOS 新装用户会看到面板与状态栏重叠）。
- **设置 → 插件 → 插件管理页的适配**：rc.2 把页面视图状态搬进了新的槽位状态，而我们在该页的**第二处注册**（设置页的「插件管理」页签）没有随之传入——在这个组合下该页会渲染失败。**本版上线前已修好**（老版本跑的是 rc.1，用户不会遇到）。

## 修复

- **任务预览「读取失败」「点了没反应」**：两处都是跨层默认语义踩空——① 直接读可选 Remote 面会抛（改为按需装配，面不在时优雅降级为「未启用」提示）；② 只带类型的页签打开被判定为「静默落位」，会开在收起的侧边栏里（现按内容型处理，打开即展开面板）。
- **轮尾卡「打开」看不到预览**：同一功能的分发链修复——内置插件改动的物化按版本比较决定是否重拷，版本未变则新代码到不了已装 profile；本版随插件 **1.0.33** 一并下发。
- **原生右侧栏压制在 rc.2 下静默失效**（本版重点修复）：上游把「面板」标记从布尔属性改成了取值属性，我们按「属性存在」写的压制规则因此匹配不到任何元素——表现为右栏会突然弹出来。已改锚到**占地的列**（列隐藏后框架的空轨道自动收为 0 宽）与**残留的拖拽分隔条**。
- **`dsh-context` 的「任务计划」… 两处补丁的落地链路**：修掉「补丁生效判据被版本门控跳过 → 恒报已生效 → 兜底注入被静默跳过」的空洞（该空洞曾让两条修复在部分用户机器上**从未生效**），并把预置声明与补丁线对齐到 **0.55.0**（此前声明锁在 0.38.x，而补丁只对 0.55.0 有效——新装用户两条修复都不落地）。
- **Windows 打开「上下文」冻结白屏**（`dsh-context` 携带的回路冷却修复）：**该修复此前就已存在，但在部分机器上从未真正生效**——补丁的「生效判据」被版本门控跳过，于是恒报「已生效」而兜底注入被静默跳过（详见下一条）。本版把链路修好，修复才真正落地。
- **「设置 → 插件管理」在 0.1.7-rc.2 组合下的渲染失败**（上线前修复，见「体验优化」）。
- **侧边栏插件的若干静默降级**：任务计划页签的预览在插件未启用 / 任务已删除 / 读取失败三种情况下分别给出明确文案，不再空白。

## 升级注意

- **定时任务默认开启**：升级后侧边栏会多出「自动化任务」入口，Agent 也可能主动提议建提醒。若不需要，可在「设置 → 插件 → 插件管理」里关掉对应行；本次是由产品策略层放开上游的默认关闭，属于产品决策而非上游行为。
- **原生右侧栏不再可用**：这是产品铁律，不是回归。原先放在右栏的上游 UI（如部分插件的侧栏页签）在 KCoder 中不可达；KCoder 的相关能力由内置侧边栏插件承担。
- **工作过程档位术语（承接 0.6.16）**：简洁 / **标准** / 详细 / 完全展开——界面上的「完全展开」是**新增的更展开档**，旧选择已自动重映射，观感不变。
- **工具描述瘦身**：模型看到的工具说明变短了（首轮提示约 −18%），行为语义不变；若你有依赖旧措辞的自定义提示词，建议复核一次。
- **上游桌面壳的修复不会随基线流入**：KCoder 使用自研 Electron 壳，上游 `apps/desktop` 的改动（安装包启动、更新提示、关窗后台运行、原生菜单图标等）与本产品无关；若遇到同类症状需单独定位。
- **内置插件版本**：随包物化终态 `dsh-coding-sidebar` **1.0.33**（本版新增「任务计划」页签的任务预览等）· `dsh-file-review-kcoder` **1.0.10** · `@kkutysllb/dsh-terminal` **1.1.1** · `dsh-skills-bundle` **1.0.2** · `dsh-shell-prefs` **1.0.1**。
- **预置声明已平移并与物化同线**：仓库约定声明（`PRESET_PLUGINS`）**只指向 npm 上已发布、可解析的版本**——未发布版本会让新装用户的 `pnpm install` 直接失败。本版由 `^1.0.32` 平移至 **`^1.0.33`**：发布核验为**指定版本端点在 npmjs 与 npmmirror 双源均 200、`dist-tags.latest` 已指向 1.0.33**（`1.0.33` 发布时在 npm 侧排队约 5 分钟，期间指定版本端点 404——故平移必须等可见之后做，顺序不可反）。
- **升级后会做一次一次性的现场维护**（幂等）：回收已退役的 `dsh-context@0.38.2.patch`、摘除指向缺失文件的补丁声明、按需重写补丁版本键——这些都会在启动日志里各打一行。
