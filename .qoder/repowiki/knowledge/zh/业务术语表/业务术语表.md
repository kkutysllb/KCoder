### KCoder
- 定义：基于 QiongQi 引擎构建的 Agent 驱动编码桌面应用，采用 Electron + React 技术栈，提供侧边栏项目导航、终端风格输入框、流式对话界面等核心功能

### preset-coding
- 定义：QiongQi 框架中的编程专用预设包，提供代码生成、文件操作、Git 管理等编程相关工具和技能，是 KCoder 应用的核心能力来源
- 别名：@qiongqi/preset-coding

### 审批策略
- 定义：Agent 执行敏感操作时的安全控制机制，支持 auto（自动批准）、on-request（请求确认）、never（从不批准）、untrusted（不可信模式）、suggest（建议模式）等策略类型
- 别名：approvalPolicy

### 工作区写入模式
- 定义：QiongQi 引擎的沙箱运行模式之一，允许 Agent 对当前工作区进行文件读写操作，区别于只读的 workspace 模式
- 别名：sandboxMode、workspace-write

### Token 经济模式
- 定义：QiongQi 引擎的 Token 消耗优化机制，通过缓存优先、去中心化编排等策略提高每个 token 的 ROI
- 别名：tokenEconomyMode
