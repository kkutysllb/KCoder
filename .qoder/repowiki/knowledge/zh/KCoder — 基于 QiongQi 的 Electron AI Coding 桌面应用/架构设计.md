仓库为顶层 pnpm workspace，包含两个子包：
- `app/`（@kcoder/app）：Electron 桌面端，使用 electron-vite 构建，main 入口 `main/index.ts` 在 app.whenReady() 后调用 `engine-host.startEngine()` 动态 import `@qiongqi/preset-coding` 与 `@qiongqi/http`，创建 coding agent 并启动绑定 127.0.0.1 的 HTTP 服务器；随后创建 BrowserWindow 并通过 preload 暴露最小 IPC 白名单。
- `engine/`（qiongqi-monorepo）：vendored 的 QiongQi 核心，按领域分层拆分为 packages/{foundation,domain-layer,ports-layer,capabilities,adapters,delegation-layer,cli-layer,http-layer,infrastructure,presets}，由 `scripts/build.mjs` 统一构建，测试用 vitest。

通信边界：渲染进程 → preload（contextBridge 白名单 send/on/off）→ main process（window/menu/settings）→ engine-host（动态 import 引擎 API）→ @qiongqi/http 提供的 REST/SSE 接口；所有引擎 API 仅监听 loopback 且依赖 runtimeToken 鉴权，CORS 默认放行 * 因同源限制。

渲染层采用 React + Vite + Tailwind + Zustand，组件按功能目录组织（ChatPanel、SettingsPanel、Sidebar、StatusBar、WelcomeScreen），状态集中在 `stores/app-store.ts`，与引擎交互封装在 `services/engine-api.ts`，认证与聊天流程通过 `hooks/useAuth.ts`、`hooks/useChat.ts` 抽象。
