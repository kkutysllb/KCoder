根目录作为顶层编排器，pnpm-workspace.yaml 声明 app、engine 以及 engine/packages/*/* 三层；package.json 提供 dev/build/package/typecheck/rebuild 等统一脚本，内部通过 --filter 或 cd engine && pnpm -r 委派到子模块。
- 运行时边界：app（Electron + Vite）的 main process 内嵌 HTTP 服务暴露 SSE 接口，React 渲染进程仅消费该 HTTP API，两者不共享进程，仅依赖 contracts 定义的请求/响应类型。
- 构建边界：engine 使用自定义拓扑构建脚本按依赖图拼装 @qiongqi/* 子包，app 侧只消费最终产物，不感知 engine 内部包结构。
- 依赖隔离：onlyBuiltDependencies 限定 better-sqlite3、esbuild、sharp、electron 四个原生包，避免全量安装；postinstall 自动触发 electron-rebuild 重新编译 native addon。
