采用 electron-vite 三进程架构：
- `main/index.ts` 为入口，按顺序启动 `engine-host`（本地 HTTP Agent）、`createWindow`、`setupMenu`，并在 `before-quit` 中优雅关闭引擎。
- `main/engine-host.ts` 通过动态 import `@qiongqi/preset-coding` + `@qiongqi/http` 拉起独立编码 Agent，随机端口 + Bearer token 鉴权，轮询 `/health` 直到就绪；对外暴露 `startEngine/stopEngine/getEnginePort/getEngineToken` 纯函数接口。
- `preload/index.ts` 使用 `contextBridge.exposeInMainWorld('kcoder', ...)` 仅暴露白名单 IPC 通道（`window-minimize/maximize/close`、`save-settings/update-engine-config` 发送端；`new-chat/open-settings/workspace-opened` 接收端），禁止渲染进程直接访问 Node/Electron。
- `renderer/src` 为 React+Vite 前端，`services/engine-api.ts` 以单例 `EngineAPI` 直连 `http://127.0.0.1:<port>` 的 Agent REST API，通过 `EventSource` 订阅 `/v1/threads/:id/turns/:tid/events` 实现 SSE 流式响应；状态由 `stores/app-store.ts`（Zustand）管理，组件位于 `components/ChatPanel/CodeBlock/FileTree/SettingsPanel/StatusBar/WelcomeScreen`。
- 构建产物输出到 `out/`，`electron-builder.yml` 将上游 `../engine` 目录作为 `extraResources` 打包进安装包，macOS 启用 hardenedRuntime + entitlements，Windows 生成 NSIS 安装器，Linux 生成 AppImage。
