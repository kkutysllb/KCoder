本模块由两个独立 npm 包组成，二者通过 `@qiongqi/contracts` 共享类型边界：
- `engine/packages/domain-layer/domain`：纯领域层，仅导出类型与无副作用的纯函数（`event.ts` 中的 `compareEventSeq`、`groupEventsByKind`；`thread.ts`、`turn.ts`、`session.ts`、`approval.ts`、`usage.ts`、`item.ts`、`thread-title.ts`、`model-history-repair.ts`、`runtime-event-reducer.ts`），不依赖任何 I/O 或适配器，作为上层编排与 UI 渲染的不可变数据源。
- `engine/packages/capabilities/skills`：技能插件能力，以 `SkillPluginHost` 为入口，按 `builtinRoots + config.roots` 扫描 `skill.json` / `SKILL.md` 并迁移到 `SkillManifestV1`（`manifest.ts` 用 zod 校验），再通过 `plugin-host.ts` 的 prompt/命令/文件类型/关键词多路匹配计算 `SkillTurnResolution`，配合 `skill-tool-provider.ts` 把声明式工具注入 `CapabilityToolProvider`，并通过 `skill-mcp-bridge.ts`、`marketplace.ts`、`work-modes.ts` 完成 MCP 服务器收集与工作模式解析。
- `engine/packages/capabilities/memory`：基于本地 JSON 文件的轻量记忆存储，`FileMemoryStore` 实现 `MemoryStore` 接口，CRUD 使用 `@qiongqi/adapter-storage` 的 `atomicWriteFile` 保证原子性，检索在 `retrieval.ts` 中做词法分词 + 技术术语加权排序，并按 `user/workspace/project` 作用域过滤。

依赖方向：domain-layer → contracts；capabilities → contracts + adapter-*；capabilities 之间相互独立，通过 contracts 暴露统一类型给 engine 上层组装。
