- 所有外部输入（manifest、memory record、capability config）均通过 zod schema 的 `safeParse`/`parse` 进行运行时校验后再进入业务逻辑，错误以 `{ ok: false, error }` 形式返回。
- 领域函数保持纯函数风格，不持有状态、不访问文件系统，仅接收不可变输入并返回新对象，便于 SSE 重放与测试断言。
- 能力实现采用工厂函数 + 配置注入模式（如 `buildSkillToolProvider`、`FileMemoryStore` 构造函数），将 I/O 细节（executor、idGenerator、nowIso）通过选项传入以便单元测试替换。
- 向后兼容通过显式的 migrate 函数处理（`migrateLegacyManifest`），旧格式先映射到新 schema 再重新 parse 以复用默认值与校验规则。
