本模块由三个职责正交的单文件单元组成，均通过 `@qiongqi/domain` 与 `@qiongqi/contracts` 的 `TurnItem` / `AgentSession` 类型与持久化 API 协作：
- `history-healing.ts`：在会话从磁盘加载后对 `TurnItem[]` 做规范化（补齐缺失 `id`、校验 `kind` 白名单与必填字段）并调用 `repairModelHistoryItems` 进行领域级修复，返回 `{ items, changed }` 供上层决定是否回写。
- `request-history-hygiene.ts`：在每次请求发送前对 `tool_result.output` 与已配对 `tool_call.arguments` 执行不可变压缩——按字节/行/token 预算裁剪文本、丢弃 base64 数据、截断超长数组并插入 `cache_hygiene_omitted_*` 占位标记，保持原始 session log 不变。
- `append-only-session-log.ts`：封装 `AgentSession` 的追加写入，维护一个可配置的 in-memory window（默认 1000），超出时仅保留尾部切片；完整历史仍由底层 `SessionStore` 持久化并通过 `loadEventsSince` 回放。
依赖方向单向向外：本模块不引入同目录其他文件，仅消费 domain/contracts 层，被 loop 主循环在“加载会话”和“构建请求上下文”两个时机分别调用。
