- 每个公共结构以 `const Xxx = z.object(...).strict()` 定义 Zod schema，并立即用 `export type Xxx = z.infer<typeof Xxx>` 同步导出 TS 类型。
- 对需要构造器的结构额外提供 `makeXxx(input: unknown): Xxx` 工厂函数，内部调用同名 schema.parse 完成运行时校验。
- 跨文件导入一律使用带 `.js` 后缀的相对路径（如 `./items.js`），遵循 ESM 裸模块规范。
- 能力类配置统一继承自 `CapabilityToggleConfig`（含 `enabled` 布尔开关），并通过 `default(() => ...)` 或 `transform` 注入默认值。
- 枚举值先定义 `z.enum([...])` 常量再 `z.infer` 出类型，禁止直接写字符串字面量联合类型。
- 事件体系采用 discriminated union：以 `kind` 字段区分变体，并通过 `RuntimeEventBase.extend({ kind: z.literal(...) })` 派生具体事件类型。
