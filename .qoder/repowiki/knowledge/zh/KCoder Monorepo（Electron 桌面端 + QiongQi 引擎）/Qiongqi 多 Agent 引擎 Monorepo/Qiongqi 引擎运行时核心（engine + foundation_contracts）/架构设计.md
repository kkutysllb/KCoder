本模块由两个层次组成：
- foundation/contracts：作为唯一契约层，被 engine/packages/engine 与 engine/packages/services 共同依赖，定义 TaskState、Turn、Thread、ToolCall、ModelRequest、RuntimeEvent 等类型以及 Zod Schema，确保各子包对领域模型的一致性。
- engine/packages/engine：按职责拆分为多个独立子包（kernel_governor、turn_orchestrator、tool_runtime、budget_continuation、compaction_recovery、history_integrity、proposal_review、middleware），通过 contracts 中的类型进行通信；services 子包则位于最外层，聚合 thread-service / turn-service / usage-service / runtime-event-recorder 作为面向上层的业务 API，内部再组合上述子包。
启动时，services 层构造 TurnOrchestrator → Kernel v3 Graph → ToolRuntimeV3 → Budget/Compaction/Middleware 链，形成「服务层 → 编排器 → 内核图 → 工具运行时 → 横切中间件」的单向依赖树，所有跨包数据交换均走 contracts 中声明的类型与事件。
