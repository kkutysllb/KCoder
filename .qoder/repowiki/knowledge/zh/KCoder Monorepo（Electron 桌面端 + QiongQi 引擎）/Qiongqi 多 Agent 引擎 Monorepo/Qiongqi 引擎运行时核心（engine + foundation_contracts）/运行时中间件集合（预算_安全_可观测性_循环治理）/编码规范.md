- 每个中间件以工厂函数形式暴露，返回 `{ id, version: 1, hooks, handle }` 结构，并通过 options 参数传入可变阈值而非硬编码。
- 在 `handle` 中统一通过返回 `{ commands: [...] }` 表达控制流，使用 `terminate/retry/jump/set-middleware-state/record-warning` 等命令类型，否则调用 `next(context)` 透传。
- 跨中间件持久化状态采用 `{ version, data }` 包裹并在读取端用 `version !== 1` 快速失败，再对字段逐一做类型收窄与默认值兜底。
- 终止场景统一产出 `status: 'degraded' | 'failed'` + `reason` + `retryable: false` + `details` 的结构体，供上层统一上报与展示。
