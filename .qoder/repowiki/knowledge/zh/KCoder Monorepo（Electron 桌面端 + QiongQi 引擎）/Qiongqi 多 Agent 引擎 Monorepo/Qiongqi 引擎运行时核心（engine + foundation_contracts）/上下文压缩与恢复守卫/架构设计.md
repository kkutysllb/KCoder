本模块由三个职责互补的纯函数/类文件组成，围绕 `TurnItem` 类型（来自 `@qiongqi/contracts`）协作：
- `context-compactor.ts` 暴露 `ContextCompactor` 类，封装软/硬阈值、模型配置驱动的 `planCompaction` 决策以及将历史前段替换为单个 `compaction` 摘要项的 `compact()` 主流程；内部依赖 `ContextEstimator` 估算 token、`model-context-profile.js` 提供每模型阈值、`compaction-marker.js` 生成摘要指纹标记、`durable-task-capsule.js` 序列化任务胶囊，并通过 `makeCompactionItem` 构造标准摘要消息。
- `context-recovery-guard.ts` 提供两个无状态检测器：`looksLikeContextLossClarification` 识别用户“上下文丢失”澄清意图，`hasRecoverableTaskState` 检查当前 `BuildContext` 是否包含可恢复的 `compaction` 摘要或活跃目标指令。
- `context-recovery.ts` 实现基于 `ProposalClass` 的状态机 `transitionContextRecovery`，对 `context_discontinuity` / `nonterminal_action` / `empty` / `length_limited` / `protocol_error` 等提案按 `recovery.attempts < recovery.maxAttempts` 推进到 `recover`，耗尽后输出 `degraded` 结果；并提供 `renderRecoveryContinuationEntry` 将 `TaskStateV1` 序列化为注入提示的权威恢复条目。
依赖方向单向向外：本模块仅消费上游的 contracts、prompt-builder、proposal-classifier、estimator、marker、capsule 等包，不反向被它们引用，作为 loop 运行时中“压缩→检测→恢复”这一横切链路的纯逻辑层。
