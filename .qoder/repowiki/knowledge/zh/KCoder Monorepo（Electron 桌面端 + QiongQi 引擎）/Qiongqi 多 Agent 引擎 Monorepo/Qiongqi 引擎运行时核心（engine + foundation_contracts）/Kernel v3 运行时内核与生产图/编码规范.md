- 节点处理器统一返回 `{ condition, value?, commands?, outcome? }` 对象，由内核的 `reduceCompletedNode` / `middlewareControlTarget` 解析为下一条边或终止结果。
- 跨节点数据通过 `set-node-data` 命令写入 `state.nodeData[nodeId]`，并以 `nodeValue` / `requireNodeValue` 读取，避免直接共享闭包变量。
- 副作用与状态变更走命令系统（`set-middleware-state`、`add-budget`、`set-task-revision`、`set-effects` 等），由 `applyCommands` 集中应用，保证可序列化与可回放。
- 对外部 I/O 错误采用条件分支而非抛出异常：如模型上下文超限返回 `degraded`，用户中止返回 `aborted`，安全拒绝返回 `fatal`，使状态机保持纯函数式。
- 生产图版本迁移集中在 `migrateGraphState` / `migrateTerminalGraphMetadata` 中，通过 `graphVersion` 字符串比较决定是否需要插入 `account-model` 或 `v1/v2-accounting-migration` 跳转。
