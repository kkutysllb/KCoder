模块由三层组成：
- `runtime-kernel.ts` 中的 `RuntimeKernel` 是纯状态机 + 事件溯源核心：通过 `RunSnapshotStore`/`RunEventStore`/`RunLeaseStore` 三个端口持久化 `RunStateV3`，以 `leaseTtlMs` 驱动 `RuntimeLeaseGuard` 周期性续租；`run()` 主循环按 `node.started → beforeNode → node handler → node.completed → afterNode` 顺序记录事件并调用 `replayAfterCheckpoint` 做幂等重放；内置 `graphVersion` 迁移（v1→v2→v3）和 `crashPoint` 注入点用于确定性测试。
- `kernel-v3-graph.ts` 的 `productionKernelV3Graph()` 声明式定义生产图的节点、边与谓词（next/final/tools/recover/wait/fatal 等），作为 `ExecutionGraph` 输入给内核。
- `kernel-v3-node-handlers.ts` 的 `createKernelV3NodeHandlers(deps)` 将依赖（thread/session/task store、promptBuilder、proposalRunner、toolRuntime、turns）注入为 `Record<string, RuntimeNodeHandler>`，每个键对应一个图节点，返回 `{ condition, value, commands, outcome }` 驱动状态转移。
依赖方向单向：handlers → kernel（通过 `RuntimeNodeHandler` 接口），graph 仅被 kernel 消费，三者共同构成“声明图 + 解释器 + 业务节点”的清晰分层。
