本模块由两个独立的 npm 包组成，共同构成「端口 + 预设」的分层：

- `@qiongqi/ports`（`engine/packages/ports-layer/ports/`）：纯接口包，仅依赖 `@qiongqi/contracts` 和 `@qiongqi/domain`，不引入任何实现。每个文件声明一组面向领域的 port 接口，如 `ToolHost`（工具执行入口）、`ModelClient`（流式模型调用）、`RunEventStore`/`RunSnapshotStore`/`RunLeaseStore`（运行期事件/快照/租约持久化）、`SessionStore`/`ThreadStore`、`ApprovalGate`/`UserInputGate`、`Clock`/`IdGenerator`、`WebProvider`、`WorkspaceInspector`、`EffectResultStore`、`TaskState` 以及聚合导出入口 `index.ts`。通过 `exports.{".":..., "./*":...}` 同时支持按包名和子路径导入。
- `@qiongqi/preset-coding`（`engine/packages/presets/preset-coding/`）：基于 HTTP 适配层 `@qiongqi/http` 的薄封装，暴露 `createCodingAgent`，把 `CODING_SYSTEM_PROMPT`、固定 agentName 与 `CODING_PINNED_CONSTRAINTS` 注入到 `QiongqiServeRuntimeOptions`，再委托给 `createQiongqiServeRuntime`；系统提示词被刻意放在请求前缀以保持 prompt-cache 稳定。

依赖方向严格单向：preset → http 适配器 → ports 接口 ← contracts/domain；ports 包自身不反向依赖任何适配器或 preset，从而保证 domain-neutral 的可插拔性。
