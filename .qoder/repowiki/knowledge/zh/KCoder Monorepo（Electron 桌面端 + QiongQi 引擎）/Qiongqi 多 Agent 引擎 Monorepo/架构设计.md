顶层 monorepo 将 Qiongqi 拆为 18 个独立 npm 包，按依赖方向划分为 L1~L8 构建层：foundation/contracts 作为所有包的共享类型契约；infrastructure 提供缓存、附件、工具运行支撑等通用能力；adapters 实现模型供应商、存储与工具适配；domain-layer + capabilities 定义领域实体与技能/记忆等纯函数式能力；engine/services+loop 与 delegation-layer 构成核心编排与子代理委派（二者形成 SCC，仅含 import type 反向边）；ports-layer 暴露领域无关端口；http-layer 与 cli-layer 分别提供 REST/A2A/KWorks 服务与本地命令入口；presets/preset-coding 把上述装配为软件工程代理预设。

- 跨包通信唯一通道是 foundation/contracts 中声明的接口与事件类型，上层只依赖抽象不依赖实现。
- 构建顺序由 scripts/build.mjs 硬编码拓扑序列驱动，绕过 pnpm -r 无法处理 SCC 的限制，并在每个包 dist/index.js 存在时判定成功。
- tests_and_scripts 位于根目录，vitest.config.ts 统一收集各子包测试，verify-* 脚本用于端到端校验（SQLite、evented A2A、崩溃恢复等）。
