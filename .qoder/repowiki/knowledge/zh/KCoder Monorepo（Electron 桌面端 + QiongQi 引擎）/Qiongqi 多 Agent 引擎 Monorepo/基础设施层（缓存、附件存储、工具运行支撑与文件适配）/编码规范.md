- 每个子包的 src/index.ts 采用 `export * from './xxx.js'` 的 barrel 模式集中暴露 API，不对外直接引用内部文件。
- 构造函数参数统一通过 options 对象传入（如 LruCache(limit)、TtlLruCache({ limit, ttlMs, now })、FileAttachmentStore({ rootDir, config, nowIso, imageTransform })），便于扩展与测试时替换。
- 对外暴露的输入/输出结构均通过 @qiongqi/contracts 中的 Zod Schema 进行解析与校验（如 AttachmentMetadataSchema.parse），保证跨包契约一致性。
- 异步 I/O 错误采用防御式 catch 返回 null 或默认值（如 get() 返回 null、maybeGenerateImageFallback 捕获 sharp 异常后降级），避免上游因基础设施细节崩溃。
