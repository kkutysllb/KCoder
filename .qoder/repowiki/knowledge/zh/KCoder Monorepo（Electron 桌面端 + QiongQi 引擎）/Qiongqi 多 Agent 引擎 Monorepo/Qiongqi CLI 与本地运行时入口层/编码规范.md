- 所有 CLI 选项统一经 `parseServeOptionsSafe` 返回 `{ ok, options | { exitCode, message, issues } }` 联合类型，错误码来自 `ServeExitCode` 常量对象而非裸数字。
- 配置来源遵循固定优先级：显式 `--flag` > `QIONGQI_*` 环境变量 > 配置文件字段 > `DEFAULT_SERVE_OPTIONS`，并通过同名 `resolveXxx` / `stringFlag` / `booleanFlag` 辅助函数实现。
- 新增子命令时先扩展 `QiongqiCliCommand` 联合与 `splitQiongqiCliCommand` 识别，再在 `runAgentCommand` 的 switch 中增加分支，保持 O(1) 路由。
- 对可插拔的 Agent 实例一律通过 `resolveRuntimeFactory(preset)` 返回工厂函数，再以 `io.createRuntime` 钩子允许测试注入 mock，避免直接 import 具体构造器。
- 对外暴露的 stdout 消息采用结构化前缀（如 `QIONGQI_READY `），便于外部进程用正则快速提取 JSON 元信息。
