- 路由统一通过 `router.add(method, path, handler)` 在 `buildRouter(runtime)` 中集中注册，路径参数使用 `:param` 占位符并由 Router 自动解码为 `ctx.params`。
- 鉴权采用三档模式：无需认证（如 `/health`）、`authenticateOrInternal`（允许内部 token 或 Bearer/Cookie）、`authorize`（仅 runtime token），并在 handler 内返回 `ERRORS.unauthorized()` / `ERRORS.notFound()` / `ERRORS.unavailable()` 等统一错误对象。
- Handler 仅依赖 `ServerRuntime` 聚合接口，不直接 import 具体 service 类型，使同一套路由可在内存态与文件态运行时之间复用。
- JSON 响应一律经 `jsonResponse(body, status?)` 构造，由 `toResponse` 统一转为标准 `Response` 并注入 `x-request-id`、`traceparent` 等可观测性头。
- 跨域请求在 `node-http-server.ts` 中集中处理：OPTIONS 预检短路返回 204，其余响应根据 `resolveAllowedOrigin` 结果附加 `Access-Control-Allow-*` 头。
