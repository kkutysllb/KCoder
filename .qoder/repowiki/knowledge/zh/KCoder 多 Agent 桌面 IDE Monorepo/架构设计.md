根目录作为顶层编排器，pnpm-workspace.yaml 声明 app、engine 以及 engine/packages/*/* 三个层次；package.json 提供 dev/build/package 等统一脚本，内部通过 --filter 或 cd engine && pnpm -r 委派到子模块。
- 运行时边界：app（Electron + Vite）通过 SSE 调用 engine 暴露的 HTTP 接口，两者不共享进程，仅依赖 contracts 定义的请求/响应类型。
- 构建边界：engine 使用自定义拓扑构建脚本按依赖图拼装 @qiongqi/* 子包，app 侧只消费最终产物，不感知 engine 内部包结构。
- 依赖隔离：onlyBuiltDependencies 限定 better-sqlite3、esbuild、sharp、electron 四个原生包，避免全量安装。
