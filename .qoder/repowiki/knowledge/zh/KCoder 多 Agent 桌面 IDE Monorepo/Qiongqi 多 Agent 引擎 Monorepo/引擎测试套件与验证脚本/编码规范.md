- 每个被测能力对应一个 `<feature>.test.ts` 文件，内部使用 `describe` 分组、`it` 描述单个行为断言。
- 通过 `makeHarness` / `buildHarness` 工厂函数集中装配 `InMemoryEventBus`、`InMemoryThreadStore`、`LocalToolHost`、`TurnOrchestrator` 等组件，测试只传入差异化的 options。
- 对外部模型调用一律用 `makeFakeModel` / `makeSilentModel` 返回的 `ModelClient` 替代，避免真实网络请求。
- 需要持久化状态的场景使用 `/tmp` 下的临时目录（如 `DATA_DIR = '/tmp/qq-crash-test'`），并在脚本末尾清理或校验残留。
- 端到端验证脚本采用带编号步骤的 console.log 输出（如 `[1] 创建 agent...`、`✅ 崩溃恢复验证通过`），失败时 `process.exit(1)`。
