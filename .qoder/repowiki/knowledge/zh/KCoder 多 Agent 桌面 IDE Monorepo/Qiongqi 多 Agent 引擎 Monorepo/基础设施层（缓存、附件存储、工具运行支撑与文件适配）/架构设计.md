本模块以 npm workspace 子包形式组织，每个子包独立 package.json + tsconfig.build.json，通过各自的 src/index.ts 做 barrel 导出：
- adapter-fs：纯函数库，封装 diff.js 的编辑匹配/差异生成、行尾归一化与 BOM 处理，供 tool-infra 消费。
- attachments：实现 AttachmentStore 接口及 FileAttachmentStore 具体实现，依赖 @qiongqi/contracts 的类型定义，内部用 node:fs/promises + crypto 将内容存为 .bin、元数据存为 .json，并可选通过 sharp 生成图片 textFallback；image-transform 作为可注入的 ImageTransform 策略。
- cache：进程内无外部依赖的 LruCache / TtlLruCache 基础类，辅以 immutable-prefix、prefix-volatility、tool-catalog-fingerprint、usage-counter、cache-telemetry 等按前缀/用途划分的辅助模块，全部由 index.ts 统一重导出。
- tool-infra：面向工具执行侧的运行时支撑——file-mutation-queue 使用 tmpdir 下的目录锁 + Map 队列对同一文件的并发写入做串行化；output-accumulator 在内存 tail 与临时文件之间自动切换，支持 UTF-8/UTF-16LE 探测与截断；command-audit、tool-rate-limit、tool-result-budget 分别负责命令审计、速率限制与结果预算。
依赖方向：adapter-fs ← tool-infra；attachments 仅依赖 contracts 与本包内部 image-transform；cache 自包含无外部运行时依赖。
