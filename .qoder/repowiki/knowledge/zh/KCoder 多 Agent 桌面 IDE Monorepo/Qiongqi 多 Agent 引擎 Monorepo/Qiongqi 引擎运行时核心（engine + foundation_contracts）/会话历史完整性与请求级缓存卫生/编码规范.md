- 所有转换函数采用不可变风格：接收输入数组/对象后返回浅拷贝的新结构，并通过布尔 `changed` 标记让调用方按需替换原引用。
- 对外暴露的入口统一以 `apply*` / `heal*` 命名，内部实现拆分为带 `compact*` / `normalize*` 前缀的纯函数，便于单测与复用。
- 大小限制同时约束 bytes、lines、tokens 三维度，并在超限时插入 `[cache hygiene: omitted ...]` 形式的占位字符串，保留可观测性。
- 递归遍历 JSON 值时使用统一的 `isRecord` 守卫与 `CompactResult<T>` 包装器，逐层聚合 `changed` 标志。
