本模块为纯类型/Schema 库，无运行时逻辑，仅依赖 zod@4 做运行时校验；通过 `package.json` 的 `exports.*` 同时发布 `.js` 与 `.d.ts`，供其他子包以 ESM 导入。

- 文件按领域切分：`events.ts`（SSE 事件 discriminated union）、`runtime-kernel.ts`（RunStateV3 / RunEventEnvelope / ScopeKey 等内核状态）、`capabilities.ts`（MCP/Web/Skills/Subagents/Attachments/Memory 六大能力开关及 `buildRuntimeCapabilityManifest`）、`threads/items/turns/approvals/review/todos/memory/workspace/policy/usage/errors` 等对应持久化实体。
- 所有公共结构均以 `export const Xxx = z.object(...)` + `export type Xxx = z.infer<typeof Xxx>` 成对导出，并在需要时提供同名 `makeXxx(input: unknown): Xxx` 工厂函数用于运行时解析。
- 跨文件引用通过相对路径 `.js` 后缀显式导入（ESM 约定），如 `events.ts` 引用 `items.js`、`threads.js`、`usage.js`、`errors.js`，形成单向依赖树，避免循环。
- `src/index.ts` 统一 re-export 全部子模块，顶层消费者只依赖 `@qiongqi/contracts` 入口；`dist/` 由 `tsc -p tsconfig.build.json` 产出，`tsconfig.json` 仅用于 `typecheck`。
- 依赖方向：本模块不依赖任何 engine 内部包，被 runtime、agent、gui、cli 等上层消费，是唯一的“向下”边界。
