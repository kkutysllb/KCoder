本模块是 `@qiongqi/services` 包，作为 engine 的运行时服务层，按职责拆分为四个并列服务：
- `thread-service.ts`：线程生命周期管理（创建、更新、删除、fork/side、resume），维护 ThreadRecord 及其 goal/todos 子域，并通过 `withFileMutationQueue` 同步计划 Markdown 中的 TODO 状态。
- `turn-service.ts`：回合（Turn）全生命周期（start/finish/interrupt/steer/compact），是唯一向外部发出 turn/item 生命周期事件的入口；内部用 per-thread 的 Promise 队列 (`threadMutationQueues` / `itemCreationQueues` / `itemUpdateQueues`) 串行化对同一 thread 的并发写入，避免竞态。
- `usage-service.ts`：聚合 token/cost/cache 用量，提供按 thread/day/model 三种维度的查询构建器（`buildDailyUsageResponse` / `buildModelUsageResponse` / `buildThreadUsageResponse`）以及 `parseDailyUsageQuery` / `parseModelUsageQuery` 参数解析。
- `runtime-event-recorder.ts`：应用级事件边界，负责给草稿事件打 seq/timestamp、通过 `EventBus` 广播、持久到 `SessionStore`，并提供 `recordOnce` 去重。

依赖方向单向向外：仅依赖 `@qiongqi/contracts`（类型）、`@qiongqi/domain`（构造器如 `createThreadRecord`/`appendTurnItem`）、`@qiongqi/ports`（抽象 Store/IdGenerator/InflightTracker/SteeringQueue/ContextCompactor）、`@qiongqi/loop`（协作接口）、`@qiongqi/tool-infra`（文件队列）、`@qiongqi/cache`（UsageCounter/CacheTelemetry）。所有 I/O 均通过注入的 port 接口完成，服务类本身不持有具体实现。`src/index.ts` 统一 re-export 四个模块作为包的对外 API。
