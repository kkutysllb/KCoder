本模块是 Qiongqi 框架面向终端/桌面 GUI 的单一进程入口，按职责拆分为四个文件：
- `cli-options.ts`：集中定义 `ServeOptionsSchema`（Zod）及默认值、preset 枚举、KWorks 数据目录计算等纯配置逻辑，被 serve 与 agent-cli 共同消费。
- `serve.ts`：实现 `parseServeOptions` / `parseServeOptionsSafe`，将 argv + env + JSON 配置文件合并为 `ServeOptions`，并导出 `SERVE_USAGE`、`ServeExitCode`、`qiongqiRuntimeStartupInfo` 等对外 API。
- `agent-cli.ts`：实现 `splitQiongqiCliCommand` 与 `runAgentCommand(run|chat|exec)`，通过 `CliIo` 抽象 stdin/stdout/stderr/env/cwd，以 `createCodingAgent` / `createAgent` 工厂选择 preset，驱动 thread/turn/toolHost 完成一次性对话、交互式 chat 和工具直调。
- `serve-entry.ts`：带 `#!/usr/bin/env node` 的 bin 入口，`main(argv)` 复用 `splitQiongqiCliCommand` 分派到 serve 或 agent 分支；serve 模式额外创建 OpenTelemetry 包装与 HTTP Server，并通过 `QIONGQI_READY <JSON>` 行向外部进程握手。
依赖方向单向向外：本模块仅依赖 `@qiongqi/http`、`@qiongqi/preset-coding`、`@qiongqi/contracts`、`@qiongqi/loop`、`@qiongqi/adapter-tools`，不反向被这些包引用；CLI 与 serve 共享同一套选项解析与 exit code 语义，保证命令行与 GUI 调用路径一致。
