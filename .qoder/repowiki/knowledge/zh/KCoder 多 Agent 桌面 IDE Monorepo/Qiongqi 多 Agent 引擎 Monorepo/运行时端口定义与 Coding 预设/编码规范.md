- 每个端口以独立文件声明接口并通过 `src/index.ts` 统一 re-export，对外只暴露类型与函数，不混入实现逻辑。
- 对外 API 采用 `Omit<QiongqiServeRuntimeOptions, ...>` 叠加可选覆盖字段的方式扩展选项，使 preset 能选择性覆写默认值而保持其余参数透传。

- 所有外部副作用（模型调用、文件 I/O、审批、用户输入）均通过 port 接口抽象并由宿主在运行时注入，核心循环不直接依赖具体实现。
