本模块以 `@qiongqi/delegation` 包形式发布，入口 `src/index.ts` 统一导出六个核心构件，内部按职责分层：
- 运行期编排层：`delegation-runtime.ts` 中的 `DelegationRuntime` 负责并发预算（`maxParallel`/`maxChildRuns`）、状态机（queued→running→completed/failed/aborted）、事件上报与用量汇总；`FileDelegationStore` 基于文件系统按 `<rootDir>/<parentThreadId>/child-runs/<id>.json` 持久化记录。
- 执行器适配层：`child-agent-executor.ts` 暴露 `createChildAgentExecutor`，将 `TurnOrchestrator` + 内存存储（`InMemoryThreadStore`/`SessionStore`/`EventBus`）组装成 `ChildRunExecutor`，供运行时注入或替换。
- 对等体抽象层：`peer-registry.ts` 定义 `LocalPeerHandle` / `RemotePeerTransport` 接口并通过 `PeerRegistry` 统一 `invokePeer(cardId, task)` 调度，依赖方向严格自下而上——HTTP 实现由上层 `@qiongqi/http` 注入，本包不直接依赖网络栈；`FilePeerStore` 仅持久化远端 peer 卡片。
- 发现与映射层：`skill-registry.ts` 扫描 `SKILL.md` frontmatter 建立 skill→agent 索引；`task-thread-map.ts` 维护编排器 thread 到子代理 thread 的映射并支持 JSON 持久化，二者均无外部依赖，可独立使用。
- 工具层：`terminal-state.ts` 提供终态判定与幂等设置辅助函数。
依赖方向：本包只向上依赖 `@qiongqi/contracts`、`@qiongqi/services`、`@qiongqi/loop`、`@qiongqi/memory`、`@qiongqi/skills`、`@qiongqi/cache`、`@qiongqi/adapter-storage`、`@qiongqi/ports`，被上层 `http` 与编排器消费，自身不反向依赖它们。
