本模块由三个独立的 npm 子包组成，均通过 `tsconfig.build.json` + `tsc -p` 构建为 ESM（`type: module`），并通过 `exports.{".":..., "./*":...}` 暴露主入口与子路径。

- `adapter-model`：以 `ModelCompatClient` / `RoutedModelCompatClient` 为核心，屏蔽 DeepSeek 等上游差异；`pricing/index.ts` 将定价抽象为 `PricingProvider` 接口，默认用 `CompositePricingProvider` 聚合 `DeepseekPricingProvider`，新增供应商只需实现该接口并注册到组合器；`tool-argument-repair`、`inline-reasoning-extractor`、`reasoning-tags`、`special-tokens` 等文件处理 LLM 协议细节。
- `adapter-storage`：围绕 `@qiongqi/ports` 中的 `SessionStore`、`ThreadStore`、`RunStateStore`、`TaskStateStore`、`EventStore` 等端口，分别提供 `in-memory-*` 与 `file-*` 两套实现，并以 `Hybrid*Store`（如 `hybrid-session-store.ts`）通过委托模式把 JSONL 正文交给 `File*Store`、索引交给 SQLite-backed `HybridThreadStore`，形成“追加日志 + 增量索引”的混合持久化策略；`atomic-write.ts`、`file-lock.ts` 保障并发安全。
- `adapter-tools`：以 `builtin-bash-tool.ts`、`read.ts`、`write.ts`、`edit.ts`、`find.ts`、`grep.ts`、`ls.ts` 等具体工具实现为主，统一通过 `LocalToolHost` 和 `createBuiltinLocalTool` 包装成 `LocalTool`；`mcp-tool-provider.ts`、`web-tool-provider.ts`、`memory-tool-provider.ts`、`delegation-tool-provider.ts` 则作为外部能力桥接；`capability-registry.ts` 与 `tool-hooks.ts` 管理工具发现与生命周期钩子；`bash.ts` 封装 Node `child_process.spawn` 执行树，支持超时、流式输出截断与审计。

依赖方向单向向下：三者都只依赖 `@qiongqi/contracts`、`@qiongqi/domain`、`@qiongqi/ports` 等上层契约包，不反向引用 engine 核心，从而保持可被外部宿主替换。
