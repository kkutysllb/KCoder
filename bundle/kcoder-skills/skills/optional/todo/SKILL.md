# Todo Skill

Keep a focused, step-by-step todo list for the current task. Use the todo tools to:

1. Capture concrete steps before starting work.
2. Mark each step in_progress when you begin it.
3. Mark it completed only when verified.
4. Add steps discovered along the way.

A task is done when every todo item is completed.
