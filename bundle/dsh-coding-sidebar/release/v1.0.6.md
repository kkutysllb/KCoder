# dsh-coding-sidebar 1.0.6

> 浏览器 tab：agent 一用 playwright 就自动切实况——一次性语义，不与用户抢控制权。

## 变更

- `BrowserView` 非实况态轮询浏览器宿主 page target（3s）：一旦出现 agent 页面
  （非 `about:` 空页）即自动开实况，并经 `betterSidebar.openTab` 把浏览器 tab
  顶到前台；
- **一次性语义**：首次自动切换后不再抢控制权——用户手动关掉实况不会被强制重开；
  宿主未起时静默等待下次轮询。

## 兼容性说明

- 依赖浏览器宿主 page target 的轮询探测；宿主缺席时零副作用（静默等待）；
- 不改 RPC 形状，其余交互与 1.0.5 一致。
