# dsh-coding-sidebar 1.0.5

## 新增

- **浏览器 tab「Agent 实况」**：agent 用 playwright 浏览时不再弹本机浏览器窗口——KCoder 桌面端
  browser-host 维护无头 Chromium（CDP 固定转发 `127.0.0.1:9223`，与 playwright MCP `--cdp-endpoint`
  共用），本插件浏览器 tab 作为第二个 CDP 客户端实时渲染 + 远控：
  - **实时画面**：`Page.screencastFrame` → canvas 渲染；视口 1280×800（Emulation 强制）；
  - **输入回传**：指针 / 滚轮按显示比例回传（`Input.dispatchMouseEvent`）；可打印字符
    `insertText`、控制键 `rawKeyDown`/`keyUp`；
  - **target 管理**：自动跟随最新创建的页面 + 下拉手动钉住；附加目标被关自动改附最新；
    3s 轮询仅在内容变化时更新 state（防重连抖动）；
  - **宿主路由** `cdp.targets`：代理 CDP `/json/list`（CDP HTTP 无 CORS 头，renderer 直连会被拦；
    WS 不受限故直连）；wire 错误码新增 `cdp-down`；
  - 浏览器工具栏新增实况开关（会话态）；文案 zh / en；LiveView 样式入 sidebar.module.css。

## 依赖

- 无新增依赖（CDP 走宿主既有 WS 通道）；包版本 1.0.4 → 1.0.5，产物
  `SIDEBAR_SERVICE_VERSION` 构建期注入同步。

## 升级

- 与 1.0.4 完全兼容（peer 钉版不变，仍为 DSH 0.1.5-rc.2）；无迁移、无契约变化。
- KCoder 侧：内置版本 1.0.4 之上顺延，预置声明语义化范围直接满足，bundle 物化按版本差自动覆盖。
- 「Agent 实况」依赖桌面端 browser-host 的 CDP 转发（127.0.0.1:9223）在位；不可用时浏览器
  工具栏开关给出 `cdp-down` 反馈，其余浏览器能力不受影响。

## 验证

- `pnpm typecheck` / `pnpm test`（openpath 回归）/ `pnpm build` / `pnpm smoke`
  （产物 + 契约 + 卫生 + 双面加载）全绿。
- 产物 `SIDEBAR_SERVICE_VERSION` 与包版本一致（1.0.5）。
