## 新增

- **Git 面板升级为「文件变动」双视角**：面板顶部新增「Git 变动 / 会话变动」切换。
  - **Git 变动**：原有 Git 面板能力不变（状态 / 暂存 / 提交 / 历史 / 折叠展开）。
  - **会话变动**：列出模型在本会话中写 / 改过的文件（从会话事件日志解析，只读回放，
    不消耗模型的 job_output 游标）， newest-first 去重列表 + 操作工具与次数；点击行展开
    文件内容预览，预览文本经过**密钥脱敏层**（API key / bearer token / 私钥块 / 口令
    赋值等启发式掩码，仅作用于本预览，不影响编辑器等普通文件读取）。
