# dsh-coding-sidebar 1.0.14

> 本版把 **v1.0.4 裁掉的文件预览线按插件上游仓库（omdsh-dev/DSH-better-sidebar）的实现恢复回来**：
> 6 个内置 viewer、`registerFileViewer` 扩展点、Markdown / Mermaid / HTML 渲染面、`/sidebar/html`
> 路由、`client-mermaid.js` 分包与相关设置项全部回归，并顺带带上上游这期间的预览面小修。

## 新增（= 恢复 v1.0.4 裁掉的面）

- **文件预览器注册表**：`ctx.betterSidebar.registerFileViewer(descriptor)` 恢复，与 `registerTab`
  同款契约（返回注销器、`getFileViewers` / `isViewerEnabled` / `matchFileViewer`）。匹配规则
  「`detect` 嗅探 → 扩展名 → 优先级（降序、稳定）」与「禁用 viewer 跳过、文件落到下一个匹配」一致，
  第三方插件可覆盖或新增预览器。

- **6 个内置 viewer**（与上游逐行同源）：

  | id | 覆盖 | 取数策略 | 渲染 |
  |---|---|---|---|
  | `image` | png/jpg/jpeg/gif/webp/svg/bmp/ico/avif | `mediaUrl` | 图片直出 |
  | `pdf` | pdf | `mediaUrl` | 会话媒体路由 + 内置 PDF 视图 |
  | `markdown` | md/markdown | `fsRead` | 预览 / 编辑双模（CodeMirror 懒加载分包） |
  | `html` | html/htm | `fsRead` | 沙箱 iframe（声明式设置带两项开关） |
  | `code` | 兜底（`exts: []`、priority −100） | `fsRead` | CodeMirror 编辑器 |
  | `binary-download` | doc/xls/ppt + NUL 探测（priority −50） | `binary-download` | 下载兜底 |

- **Markdown 预览渲染面**：内嵌 HTML 消毒渲染（DOMPurify + 显式 denylist，块级 run 提升为真实 DOM、
  未闭合标签按浏览器线性解析降级包裹、表格单元格内 `<br/>`/`<sub>`/`<img>` 行内还原）、≥3 标题的
  浮动**目录大纲**（点击平滑滚动 + 自动展开 `<details>` + 命中高亮）、本地 / 相对图片与引用式
  `[id]: url` 目标改写为 `/sidebar/file` 媒体路由（代码块 / 行内代码掩码，普通链接的引用定义不动）。

- **Mermaid**：含 mermaid fence 的 markdown 按需下发 `client-mermaid.js` 分包（**7,033,906 字节**，
  无 mermaid 文件零加载）；`securityLevel: 'strict'` + `htmlLabels: false` + SVG 注入前二次清洗
  （删 `foreignObject`/`script`/外来元素，剥 `@*`/`on*`/`href`），点击弹窗放大（滚轮缩放、拖拽平移、
  Esc 关闭），深浅色跟随重渲、解析失败回退原码。

- **宿主路由**：`/sidebar/html` 预览路由恢复（路径编码保留会话作用域，相对资源可回路由；workspace
  包含性校验 + 大小上限 + `content-security-policy: sandbox …; object-src 'none'` 纵深防御），
  `/sidebar/bundle` 的 chunk 白名单重新接纳 `mermaid`。

- **设置面**：「文件预览」网格恢复——每个 viewer 一行开关（写 `viewersEnabled[id]`）+ 声明式
  设置（HTML 沙箱两项：`htmlViewerNoSandbox` 全局关闭沙箱、`htmlViewerDefaultUnsafe` 默认以非沙箱
  打开，均带警示文案）；网格末尾虚线卡片恢复**预览插件目录**（Office 三件套 / 视频预览插件）。

- **i18n**：26 个 key（预览 / 目录 / 编辑 / mermaid 缩放四连 / viewer 名称 / HTML 沙箱三连 /
  预览插件卡）× 21 个词典，键数 444 → **470**，构建期 `checked()` 仍强制全键集。

## 与上游的对齐度

- **逐字节同源**（`diff` 为空）：`mermaid.tsx`、`mermaid-blocks.ts`、`mermaid-sanitize.ts`、
  `markdown-html.ts`、`editor-load.ts`、`image-types.ts`、`pdf-types.ts`、`html-route.ts`、
  `chunks/mermaid.tsx`、`builtins/viewers.tsx`、`SandboxStatusBar.tsx`，以及
  `markdown-images.ts` / `PdfView.tsx` / `md-toc.tsx`（直接取上游当前版）。
- **融合点**：`TextEditor.tsx` 不是简单取回——本仓库 v1.0.4 之后把选区弹层重构成了
  `selection-popup.ts` 的 `useSelectionPopup` hook（上游同期也做了同一重构），本版以**上游预览线 +
  我们的 hook 形态**手工三方合并：`getSurface` 在 markdown 预览态指向预览容器、其余指向 CodeMirror，
  编辑态与预览态各一条选区弹层入口。
- **顺带移植的上游小修**：`md-toc.tsx` 点预览空白处关闭大纲（pointerdown 命中判定，按钮与面板豁免）；
  `PdfView.tsx` 的 scope 依赖粒度注释；`MarkdownHtml.tsx` 的 markdown run 也走
  `rewriteLocalImageUrls`（否则内嵌 HTML 文档里的本地图片在 `MarkdownText` 的 http(s) 白名单下只剩
  alt 文本）。
- **不在本版范围**（上游 v1.0.4 之后新增、与本仓库当前形态无接缝的预览相关演进）：frontmatter
  抽取模块、`html-preview.ts` 的沙箱常量拆分、`mermaid-lazy.tsx` 拆分（我们仍由 `MarkdownHtml.tsx`
  导出 `LazyMermaidMarkdown`）、Office / markdown 导出 / 代码导航三条推荐插件目录条目、
  `tree-mutations.ts` 与 `editor-load.ts` 的后续演进。
- **已知同款行为**：行内图片的 title（`![a](./x.png "t")`）在改写目标时不保留——上游同款实现，
  本版按契约断言住（预览里 title 只影响 tooltip）。
