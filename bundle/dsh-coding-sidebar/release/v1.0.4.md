# dsh-coding-sidebar 1.0.4

## 退役

- **文件预览线整体退役**：DSH 0.1.5-rc.2 内置文件预览已完善，侧边栏不再承担任何预览职责——
  - 移除全部 6 个内置 viewer（图片 / PDF / Markdown / HTML / code 兜底 / binary-download）与
    `registerFileViewer` 扩展点：`ctx.betterSidebar` 服务面收缩为仅 tab 注册
    （`registerTab` / `openTab` / `openFile` 等全部保留），`FileViewerDescriptor` /
    `FileViewerProps` / `FileFetchStrategy` 类型不再导出；
  - 移除 Markdown / Mermaid / HTML 富预览渲染面与 `client-mermaid.js`（约 7MB）分包，
    `mermaid`、`dompurify` 依赖随包移除；`/sidebar/html` 预览路由下线；
    `/sidebar/file` 保留（服务非文本文件的下载兜底）；
  - 设置项 `htmlViewerNoSandbox` / `htmlViewerDefaultUnsafe` / `viewersEnabled` 移除；
  - CodeMirror 编辑器保留为**纯编辑**（行号 / 换行 / 语法高亮 / Ctrl+S 保存）：
    explorer 双击文本文件直接进编辑 tab，非文本文件走下载兜底面板；
  - 迁移指引：预览类衍生插件（Office 预览 / 视频预览 / Jupyter / 预览划选增强等）不再受支持，
    请改用 DSH 内置预览；聊天侧「文件打开进侧边栏」拦截不变（进纯编辑 tab）。

## 新增

- **原生侧边栏避让**：DSH 原生侧边栏展开时，展开中的侧边栏面板自动收起让出空间
  （避免页面被切成多栏）；原生侧边栏关闭后自动恢复展开。
  - 检测走宿主 slot 出口的 `data-slot^="sidebar."` 语义锚点 + ResizeObserver 宽度阈值
    （文档化收窄轨道 56px）；锚点缺失时功能静默不激活；
  - 避让 ride 常规 `panelOpen` 状态：开关按钮、内容打开自动展开、按会话持久化等契约不变；
  - 用户手动开关 / 内容打开即时接管面板归属（此后原生侧栏关闭不强制恢复）；会话切换重评估。

## 依赖

- peer / devDeps / workspace 钉版 0.1.5-rc.1 → 0.1.5-rc.2（含 `minimumReleaseAgeExclude`
  集合同步）；`mermaid`、`dompurify` 依赖移除。

## 升级

- 需要 DSH 0.1.5-rc.2 宿主；对 rc.1 及更早宿主不承诺兼容（钉版已迁移）。
- KCoder 侧：内置版本 1.0.3 之上顺延，预置声明语义化范围直接满足，bundle 物化按版本差自动覆盖。
- 已打开的预览类 tab（编辑器型）升级后自动以纯编辑模式继续工作，布局无需迁移。
