# dsh-coding-sidebar 1.0.20

> 0.1.6-alpha.2 适配补刀：列表级 `current` 被上游移除后，当前会话推导。

## 背景

dsh 0.1.6-alpha.2 的 `SessionListState` 不再有 `current` 字段（契约注释：
navigation belongs to view owners——"当前会话"从服务状态挪给视图所有者）。
插件旧读法 `sessionList.current` 在新引擎恒为 `undefined`，于是**即便主
视图里开着会话**，插件也走「无会话」占位分支：开关按钮置灰、点不动
（dev 现场：`aria-label` 停在「选择一个会话以使用侧边栏」）。

## 变更

`Sidebar.tsx` 当前会话推导改为两级：旧引擎读 `current`；新引擎按
**主视图保留计数** `retainedBy.mainView > 0` 推导——与上游自己的推导
逐字同款（`ui-session` 的 `publishMain` 兜底、`ui-workspace` 树的
活动会话高亮均用此规则）。

`context-types.ts` 的 `SidebarSessionSummary` 补结构性可选字段
`retainedBy?: { mainView?: number }`（旧类型基线无此字段，不引新类型）。

typecheck / build / test / smoke / check:artifacts 全过。
