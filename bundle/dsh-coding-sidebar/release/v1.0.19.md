# dsh-coding-sidebar 1.0.19

> 协调补丁：file-review 复活后的让位规则（turnTail list 共存的最后一块）。

## 变更

`SidebarTurnTail` 新增退位条件 `hasFileReviewData`：turn 带有
dsh-file-review-kcoder 的 `fileReviewChanges` turn data（该插件组入即有，
与 git 无关）时，本行渲染 null——其增强卡（hunks/统计/撤销 + 产物与
交付两段）已覆盖该 turn，双行无信息增量。

背景：chain 时代的协调是 file-review（priority -2）选举先于本行（-1），
天然单行。alpha.2 list 语义无抢占，改为数据探测互让：changes 公告 →
原生卡；fileReviewChanges → file-review 卡；其余（无 git 快照服务的工作区
的工具改写 turn）→ 本行兜底。同一 turn 永不双行。

## 验证

typecheck / build / test / smoke 全过；与 file-review 1.0.5-wip 双插件
alpha.2 引擎活体共载零页面错误。
