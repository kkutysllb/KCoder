# dsh-coding-sidebar 1.0.15

> 本版补齐 **Office 文档与视频预览**（docx / xlsx / pptx / 16 种视频格式 + HTTP Range 流式拖动），
> 并为 QiLin 分发通道带来设置页接管与文件地址 scheme 适配。

## 新增

- **docx / xlsx / pptx 预览器**：`mediaUrl` 取数 + 新懒加载分包 `client-office.js`
  （docx 文档预览、xlsx 经 Univer 电子表格渲染、pptx 经 `@aiden0z/pptx-renderer` 渲染），
  与既有 viewer 同契约：注册表可见、设置页可禁用、扩展名匹配、禁用后落到下一个匹配。

- **视频预览器**：mp4 / webm / mov / qt / m4v / mkv / avi / wmv / flv / ogv / ogg / mpeg / mpg /
  3gp / 3g2 / m2ts 共 16 种扩展名
  （`ts` 刻意不认——它是 TypeScript）。宿主媒体路由支持 **HTTP Range 请求**：
  `serveMediaRange` 以 206 分段流式应答、416 语义与倒置区间（`bytes=5-3`）忽略而非 500；
  Range 请求流式发送、不整档进内存，因此不受 `mediaLimit` 整档上限约束——
  视频拖动进度条即点即播。

## QiLin 分发通道（内置 + 在线升级）

- **设置页接管**：通道构建下设置节以原生 `sidebar-right` 单元格 id、priority -1 注册
  （槽位遮蔽语义：同单元格低优先级者胜出），原生「侧边栏」设置页与导航行被「侧边卡片」
  页取代；通道差异集中在新文件 `src/client/channel-policy.ts`，DSH 通道行为不变（共存）。

- **文件地址 scheme**：`FILE_ADDRESS_PREFIX` 在通道构建下重写为 `qilin-resource://file/`
  （QiLin 侧 `fileAddressFor` 的改名），聊天区文件打开在 QiLin 下真正落入工作台编辑器。

- **身份徽标**：设置页徽标显示通道包名（DSH：`dsh-coding-sidebar`；QiLin：
  `@qilin/coding-sidebar`）。

- **生成/对账工具**：`scripts/sync-to-qilin.mjs`（vendored 副本重建，`--check` 零漂移）与
  `scripts/qilin-channel/tsdown.config.ts`（通道构建模板）。

## 修复

- `parseRange` 索引访问类型（`noUncheckedIndexedAccess` 下 `tsconfig.build.json` 构建面报错）。
- QiLin 兼容：client inject 列表去掉 `workspaces`、`connection.api` 缺失时聊天转录分页
  优雅降级、`*.css` 模块声明、`ActivityEvent` 数据形状放宽为 `unknown`。

## 升级注意

- **先卸载两个已被收编的衍生插件**：`@huanlin/dsh-plugin-better-sidebar-plugin-office`
  与 `dsh-video-preview`。它们注册的 viewer id（`docx` / `xlsx` / `pptx` / `video`）自本版起
  由本包内置，同时安装会在插件激活时报 `already registered`；设置页的推荐预览插件目录
  同步清空（不再推荐这两个包）。
- **首次打开 .docx / .xlsx / .pptx 会按需拉取约 22MB 的 `client-office.js` 分包**
  （docx-preview + Univer/SheetJS + pptx-renderer）——核心包不受影响，只有真正打开
  Office 文件时才下载（同 mermaid 分包的机制）。
- 视频预览走 `/sidebar/file` 的 Range 流式分支：非 Range 请求的行为与取数上限
  （`mediaLimit`，默认 20MB）保持原样不变。
