# dsh-coding-sidebar 1.0.13

> 本版把 `@kkutysllb/dsh-git-panel` 面板的能力并入侧边栏「源代码管理」，并把它的「任务计划」
> 区块提升为一个独立 Tab —— 该内置插件随后可退役。

## 新增

- **「源代码管理」补齐 Git 面板差距**（面板原能力 → 侧边栏）：

  | 能力 | 本版落点 |
  |---|---|
  | 上游距离（ahead/behind / 已同步 / 待推送 / 无上游） | 变更视图顶部徽标，随静默轮询刷新 |
  | 推送 / 提交并推送 | 提交框下的推送行；无上游时宿主自动 `push -u origin <branch>` |
  | 逐文件行数 `+N −M` | 变更行尾；未跟踪文件按正文计行（2MB / 400 文件 / 并发 16 有界） |
  | 分支视图 | 搜索、新建并检出、检出远程短名（建跟踪分支）、删除（安全删被拒 → 二次确认强制删） |
  | GitHub 视图 | 开放 PR / Issue 列表与计数、当前分支标记、创建 PR（缺上游自动推送）、Squash/Merge/Rebase 合并（行内二次确认）、新建 Issue；`gh` 缺席 / 未登录可读降级 + 重新探测 |

  宿主侧新增 `src/github.ts`（`gh` 软依赖：probe/list/create-pr/merge-pr/create-issue，全部 `argv`
  直调、标题与描述永不经 shell）与 `src/git.ts` 扩展（`aheadBehind`/`pushBranch`/`createBranch`/
  `deleteBranch`/`branchRows`/`summary` + 纯解析器），共 10 条新路由；`not-merged` 升级为独立
  wire 错误码，前端据此弹出强制删除的二次确认。

- **📋 任务计划（独立 Tab，order 32）**：扫描工作区里 agent 写的计划文档——约定位置 `plans/` ·
  `docs/plans/` · `.plans/`（各一层 `*.md`）与根 `plan.md` / `PLAN.md` / `docs/plan.md`，按
  `dev:ino` 文件身份去重（大小写不敏感盘上 `plan.md` 与 `PLAN.md` 是同一文件）、按修改时间倒序、
  上限 20（面板当年是卡片内一块、只显示 6）。行标题取文档首个 `#`~`###` 标题，只读 **512B 头部**
  （不整文件读），无标题或不可读回退文件名；行副标题是相对路径 + 相对时间（走插件既有的
  `relativeTime`，21 个词典各自本地化）。点击在侧边栏自己的编辑器 Tab 打开，行尾按钮交给**系统
  默认应用**（新增 `openFileCommand`/`launchExternalFile`，宿主侧限定工作区内 + 文本扩展名白名单
  `.md/.markdown/.txt`）。可见时 4s 轮询，支持标题 / 路径搜索与手动刷新。

- **i18n**：63 个新 key（git 面 55 + 任务计划 8）× 21 个词典，构建期 `checked()` 强制全键集。

## 说明（与 Git 面板的差异）

- 面板的「任务计划」原本是卡片里的一个区块，本版按用户要求**独立成 Tab**，因此比面板多出：独立
  搜索、上限 6 → 20、「仅显示最近 N 份」提示、本地化相对时间。
- 面板的提交按钮在「无暂存但有变更」时自动 `add -A`；本版保留该语义，但**只在索引为空时**才自动
  全量暂存——用户在别处做过的选择性暂存不会被覆盖。
- 面板 `open-plan` 的系统打开是**回退链末端**（有侧边栏时优先走侧边栏编辑器）；本版同样以侧边栏
  编辑器为主路径，系统打开降级为行尾按钮，且比面板多了工作区包含性校验与扩展名白名单。
- 面板的 `gh` 报告与本版一致为软依赖；本版额外把 base 分支校验挪到**任何推送副作用之前**
  （面板顺序下非法 base 会先把分支推上去）。
- 未移植：面板的按钮注入标题栏、以及它自己那套折叠卡片 UI——侧边栏已有等价的 Tab 形态。
