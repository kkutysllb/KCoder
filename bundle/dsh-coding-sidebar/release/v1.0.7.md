# dsh-coding-sidebar 1.0.7

> 1.0.6 已发布 npm 但未建 tag / 发布说明；本版发布说明一并覆盖 1.0.6 的功能。

## 新增（1.0.6）

- **Agent 实况自动切换**：agent 一用 playwright 浏览（宿主 CDP 出现 agent 页面），浏览器 tab
  自动打开「Agent 实况」——不再需要手动点开关；agent 会话结束（CDP 上不再有 agent 页）自动关回。

## 修复（1.0.7）

- **杜绝实况 tab 风暴**（1.0.6 的自动切换两处缺陷，表现为引擎反复重连、侧边栏浏览器 tab
  关不掉、只能重启应用）：
  - **边沿触发**：自动切换改为边沿判定——上一拍须明确观测过「无 agent 页」才武装（首拍永不
    触发），重挂载 / 页面重载不再重新武装，手动关掉的实况不会被强制重开；
  - **顶前台改 `activateTab`**：原实现用 `openTab({type:'browser'})` 顶前台，而 browser 类型
    `openTab` 经 `createTab` 每次铸唯一 id 新 tab（无 dedupe），自动切换在新挂载组件里每拍
    mint 新 tab，几何级繁殖打爆渲染进程；现改为 `activateTab(本 tab)`。

## 依赖

- 无新增依赖；版本 1.0.5 → 1.0.6 → 1.0.7，产物 `SIDEBAR_SERVICE_VERSION` 构建期注入同步。

## 升级

- 与 1.0.5 / 1.0.6 完全兼容（peer 钉版不变，仍为 DSH 0.1.5-rc.2）；无迁移、无契约变化。
- **npm 上的 1.0.6 用户建议升级**：1.0.6 的自动切换存在 tab 风暴缺陷（见上），1.0.7 修复。
- KCoder 侧：预置声明语义化范围直接满足，bundle 物化按版本差自动覆盖。
- 「Agent 实况」依赖桌面端 browser-host 的 CDP 转发（127.0.0.1:9223）在位；不可用时给出
  `cdp-down` 反馈，其余浏览器能力不受影响。

## 验证

- `pnpm typecheck` / `pnpm test`（openpath 回归）/ `pnpm smoke`
  （产物 + 契约 + 卫生 + 双面加载）全绿。
- 产物 `SIDEBAR_SERVICE_VERSION` 与包版本一致（1.0.7）。
