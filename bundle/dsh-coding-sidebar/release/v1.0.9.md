# dsh-coding-sidebar 1.0.9

> 本版为「上游 v0.19.x 功能线回流」第二批：三个面向 agent 工作流的体验升级。

## 新增

- **终端等待 banner + 跳过等待**：agent 执行 `terminal_wait_for` 阻塞等待时，对应终端
  顶部显示「Agent 正在等待 {needle}」横幅与「跳过等待」按钮，终端 tab 标题加 ⏳ 徽章；
  跳过后工具立即返回 `skipped`（与超时/退出区分），等待状态经 agent-terminals 推送实时
  同步（瞬态，不持久化）。
- **`terminal_wait_for` needle 支持正则**：needle 按 JavaScript 正则优先（编译失败回退
  字面匹配，旧用法完全兼容），`found` 结果新增 `match` 字段回报实际命中文本——一个
  needle 可覆盖多结局（如 `(BUILD_OK|BUILD_FAIL)`），`match` 区分命中分支。
- **文件树重命名 / 删除**：右键菜单新增「重命名」（行内编辑：预填全选、Enter/失焦提交、
  Esc 取消、IME 守卫）与「删除」（Modal 确认，文件/目录文案区分，永久删除）。安全语义：
  单路径段、目标已存在 409、根目录拒绝、软链接只动链接本身；打开的 tab 自动调解
  （改名重定向路径与标题、删除关闭受影响 tab）。
- **git diff 折叠行真实展开**：hunk 之间的省略区间渲染为「展开 N 行上下文」折叠行，点击
  经 `git.fold-contents` 取两侧全文（commit / staged / unstaged 三种形态）异步物化隐藏
  行（加载中不可点、失败降级静态标记、Promise 缓存去重并发点击）。

## 依赖

- 无新增依赖；版本 1.0.8 → 1.0.9，产物 `SIDEBAR_SERVICE_VERSION` 构建期注入同步。
- typecheck / build / smoke 全绿。

## 升级

- 与 1.0.5 – 1.0.8 完全兼容（peer 钉版不变，仍为 DSH 0.1.5-rc.2）；无迁移。
- `terminal_wait_for` 的 output schema 新增 `skipped` 分支（oneOf 追加，旧调用方无感）；
  `agent-pty.skip-wait` 为新增路由，均向后兼容。
