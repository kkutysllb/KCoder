# dsh-coding-sidebar 1.0.3

## 适配

- **宿主对齐 DSH 0.1.5-rc.1**：peer / devDeps / workspace 钉版 0.1.2-alpha.2 → 0.1.5-rc.1
  （含 `minimumReleaseAgeExclude` 集合同步）；移除 `dsh-invariants` peer
  （0.1.5 上游 llm 层已剥离，仓库无实际 import）。
- **Session API 迁移**（0.1.5 起 `events` 私有化、persistence handle 重构）：
  `.events` 属性 → `snapshotEvents()`；`persistence.inspect()` → handle-seam（open / read / close）；
  `CreateAgentOptions.meta.seedLength` → `isSeeded`。
- **CSS 对齐 0.1.5 变量体系**：hairline → `border-l`；accent 系（0.1.5 已无 accent/danger 文本变量）
  → `interactive-bg-hover-solid` / 具体值 fallback；`font-s-13` → `font-s-14`；
  dsw 变量引用全量对上游存活校验通过。
- README「支持的 DSH 版本」徽章同步更新为 0.1.5-rc.1。

## 明确不做

- tab → `sidebar.right.pane.tab` 迁移（UI 后置批次）。

## 升级

- 需要 DSH 0.1.5-rc.1 宿主；对 0.1.2-alpha.2 及更早宿主不兼容（Session API 与 CSS 变量体系已迁移）。
- KCoder 侧：内置版本 1.0.2 之上顺延，预置声明语义化范围直接满足，bundle 物化按版本差自动覆盖。

## 验证

- `pnpm typecheck` / `pnpm test`（openpath 回归）/ `pnpm smoke`（产物 + 契约 + 卫生 + 双面加载 25 项）全绿。
- 产物 `SIDEBAR_SERVICE_VERSION` 与包版本一致（1.0.3）。
