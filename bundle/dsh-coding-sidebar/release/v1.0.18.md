# dsh-coding-sidebar 1.0.18

> 0.1.6-alpha.2 适配版：turnTail 槽位 chain → list 语义重写 + 与原生交付物行共存规则。

## 背景

上游 dsh 0.1.6-alpha.2 把 `conversation.chat.turnTail` 从 **chain**（select 选举 +
priority 抢占，一个条目独占整行）改为 **list**（每个条目渲染自己的行，注册必须带
id，select/priority 已不存在）。旧注册在 alpha.2 上直接抛错：

```
list slot "conversation.chat.turnTail" requires options.id
```

实测宿主侧（host 半）在 alpha.2 上激活、加载、渲染全部正常——本槽位是**唯一**
断点。

## 变更

- `src/client/intercept.tsx`：注册改 list 语义（`id: 'dsh-coding-sidebar'`，
  去掉 select/priority）；匹配/退位判定移入组件 `SidebarTurnTail`（每次渲染重算）。
- **共存规则取代抢占**：list 语义下无法抢占原生条目，改为在组件内退位（渲染
  null），保证同一份文件永不双行：
  - turn 带 `workspace/changes` 公告 → 原生 changed-files 卡会出 → 退位（其
    chips 仍经 openResource 拦截落进本侧边栏编辑器）；
  - 声明式交付（present 卡）→ 原生行的事，维持旧语义；
  - 无产出 / 编辑器 tab 停用 / 侧边栏挂起 → 照旧退位。
- 新增 `hasChangesAnnouncement(owner)`：结构性读取 turn data（与
  `hasDeclaredDeliveries` 同款配方，不依赖新类型发布）。
- peer 范围：12 个 `@deepseek-ai/dsh-*` 从 `^…alpha.1` 放宽为
  `^…alpha.1 || ^…alpha.2`。

## 语义影响（行为变化）

抢占时代的「产物行整行接管」不复存在。本行的新职责是**补原生交付物的缺口**：
无 changes 摘要服务的工作区（非 git 等）里的工具改写 turn。git 工作区的常规
turn 由原生 changed-files 卡展示（数据更权威：Host git 快照 numstat）。

## 验证

- typecheck / build / test（全量 PASS）/ smoke（产物+契约+卫生+双面加载）全过；
- alpha.2 引擎活体（npm 装包 + 重建产物覆盖）：host 半激活无告警、client 半
  正常加载、插件宿主渲染、`requires options.id` 错误消失、无页面错误。
