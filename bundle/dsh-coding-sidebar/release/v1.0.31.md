# dsh-coding-sidebar 1.0.31

> 客户端图清单纠偏：`dsh.client.inject` 改列 0.1.7 真实存在的图行，去掉已消亡的
> `@deepseek-ai/dsh-client-runtime` 与类型包 `ui-slots`；**无行为改动**。
> 本版同时是 **1.0.29 / 1.0.30 的发布载体**（两版未单独上架 npm）。

## 变更

### 客户端清单：inject 改列真实图行（7 条）

- 去掉 `@deepseek-ai/dsh-client-runtime`：0.1.7-alpha.1 已无此包（末版
  `0.1.1-rc.2`）。清单是客户端图的**到达序提示**，指向不存在的行会被
  `client-modules` 的 `graphRows` 查找**静默跳过**——不影响启动，但清单失真会
  掩盖真实依赖、让排障时误以为该包仍是契约的一部分。
- 去掉 `@deepseek-ai/dsh-client-ui-slots`：它只是类型包（`PropsRuntime` 类型
  导入），不是客户端图行；`slots` 的图行提供方是 `ui-renderer`。
- 改列真实提供方 7 条：`dsh-api-remotes`、`dsh-api-session-controller`、
  `dsh-client-connection`、`dsh-client-locale`、`dsh-client-modules`、
  `dsh-client-ui-conversation`、`dsh-client-ui-renderer`——服务面对应
  `remote`(+`remote.session`) / `sessions` / `connection` / `locale` / `modules`
  / `slots`，外加轨迹图经 `ctx.get('uiConversation')` 探针订阅的宿主
  trajectory target 行；**`src/client/index.tsx` 的 inject 数组未改动**。

### 冒烟闸门同步（`scripts/smoke-plugin.mjs`）

- `dsh.client.inject` 断言由钉死的「五件套」改为上列 7 条图行清单；旧断言钉着
  已消亡的 `dsh-client-runtime` 与类型包 `ui-slots`，在本版清单变更后必然失败
  （prepack 会拦下发布），故随本版一并收口，并补注释写明判据。

### 产物刷新

- `lib/client.js` / `lib/client-registry.js`：随清单与版本号重建（横幅版本由
  tsdown 从 `package.json` 注入，本版为 1.0.31）。
- `lib/client-office.js`：换用**干净全量重建**产物。已提交版本来自 watch/增量
  构建，与干净重建存在字节分歧（多内联一份 `react-is@16` 开发包、
  `isRegExp` → `isRegExp$1` 改名、体积差）——与 v1.0.27 命中过的成因同类；
  已确认连续两次干净重建字节一致后再提交。

## 兼容性说明

- **无行为改动**：清单只是到达序提示，1.0.30 及更早的宿主组合行为不变；
  `client-office` 的刷新只改分包内部打包形态，docx / xlsx / pptx 三个视图导出不变。
- peer 范围不变（`^0.1.5-rc.2 || ^0.1.6-alpha.1 || ^0.1.6-alpha.2 || ^0.1.7-alpha.1`）；
  `ui-slots` / `ui-primitives` 等**类型包仍在 peer 声明内**，只从图清单移除。
- npm 通道自 1.0.28 起未再上架：本版把 **1.0.29**（settings 命名空间 →
  0.1.7 profile-config / volatile 迁移）与 **1.0.30**（0.1.7-alpha.1 契约批：
  图标命名 / V4 source kind / jobs caller / 依赖平移）一并带到 `latest`；
  **0.1.7 线宿主请安装 ≥ 1.0.31**。
