# dsh-coding-sidebar 1.0.26

> sidechat 活跃线程的停用收口 + 依赖治理：`ws` 转 peer 依赖、`cordis.patch.yml` 随包导出。

## 变更

### sidechat 活跃线程停用收口

插件停用/卸载（HMR）时，本 activation 仍存活的 sidechat 子 agent 此前会留在
宿主 AgentRegistry 里继续跑。现注册 `ctx.effect` teardown：`releaseAllThreads()`
逐个 await 释放并清空 `threadDisposers` / `pendingSnapshots` 两张表，失败
（agent 已随重启消失）不阻断卸载。插件管理器「等已移除插件释放资源及 Loader
树稳定」后才继续 `pnpm remove`，不再有漏网线程；会话与历史保持持久化，语义与
`sidechat.dispose` 路由一致（只释放 live agent）。

### 依赖治理

- `ws ^8.18.0` 从 `dependencies` 移到 `peerDependencies`：终端 WS 闭包交由
  宿主提供，不再自持重复拷贝。
- `exports` 增补 `./cordis.patch.yml`：包声明 `exports` 后子路径默认不可达，
  补上后安装器/工具链可按包内路径读取 patch 文件。
