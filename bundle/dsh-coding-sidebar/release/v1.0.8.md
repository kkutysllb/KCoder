## 修复（移植上游）

- **终端**
  - WS close reason 按 UTF-8 字节截断（≤123 字节，不切碎 code point），避免超长抛错；
  - PTY resize 三重容错：非有限维度拒绝、瞬时失败吞掉、Windows 下 pty 退出后的延迟 resize
    用布防门（首帧输出后重放 pending）；
  - 自定义字体解析失败兜底等宽栈，避免比例字体毁掉字符网格；
  - **shell 配置加固**：引号感知参数解析与路径去引号纯函数、双平台（POSIX/Windows）
    spawn 前预检可执行文件、统一 `shell-not-found` 错误码 + 本地化可操作横幅
    （`terminalShellNotFound`，22 份词典全补）。
- **文件 / Git**
  - 窗口聚焦自动刷新文件树（+ 可 dispatch 的 `dsh-sidebar:refresh-files` 事件）；
  - Windows explorer「显示所在文件夹」保留选中（`/select,<path>` 单参数）；
  - 旧版 Git（< 2.36）`worktree list` 无 `-z` 自动回退（能力探测缓存）。
- **会话 / 布局**
  - 自动激活（新子代理 / 新后台任务）在窄屏不再强制展开全屏抽屉；宽屏才同时展开侧边栏
    （设置文案同步改写，21 份词典）；恢复时窄屏保持抽屉关闭；
  - 自由窗口恢复 id 冲突修复（`maxCounterId` 此前未统计 `float:` 前缀，新建自由窗口会与
    持久化窗口撞 id——本分支特有缺口被上游修复覆盖）。
- **侧边对话 / 编辑器**
  - 选区弹层文本插入到 composer 光标处（空白感知拼接、替换选区、过期光标回退尾部）；
  - 草稿插入后恢复 composer 光标（值同步校验 + 两帧重试）；
  - @-引用文件改走 DSH 结构化 `slash/input-insert-reference` 事件铸整链 chip（显示
    `@basename`、序列化完整 `@path`），目录保持 `@dir/`，结构化失败回退纯文本；
  - 选区弹层新增五路收起契约（外点 mousedown / Escape / visibilitychange / window blur /
    表面离开视口 IntersectionObserver）。
- **侧边对话种子契约**：种子补全 fork 标记对（`isSeeded: true` +
  `inheritedEventCount: SessionLogOffset(seed.length)`），修复子线程重放父会话未领取
  inbox 的幽灵消息（上游 93ad87d，1.0.7 线已先行合入 fe61fd4）。
