# dsh-coding-sidebar 1.0.25

> 新增「智能体团队」tab：上游 `agentTeams` 数据面 + 自家侧栏的名册与任务看板。

## 变更

### 数据面（只用上游的数据面，不用它的 UI）

- 新增 `src/team-types.ts`：按线格式**结构化镜像**上游视图（`TeamView` /
  `TeamMemberView` / `TeamTaskView` / 请求与业务结果）——本包是独立仓，上游
  experimental 包不是它的依赖，镜像口径与 `openpath-intercept` 的文件地址语法一致；
- 新增 `src/team-routes.ts` + 宿主接线：`team.view` / `team.createTask` /
  `team.updateTask` 三条桥路由，用 `ctx.get('agentTeams')` +
  `ctx.agents.get(sessionId)` 解析**调用者身份**（服务按现役 Agent 校验名册），
  视图与业务结果原样返回。服务缺席时返回 `service-missing` / `agent-missing`，
  不抛错、也不自动挂载该服务。

### 客户端

- 新增 `TeamView.tsx` + `TeamView.module.css`：名册（状态点 / 模型 / 诊断，点队友
  开会话）+ 任务看板（新建 / 编辑 / 依赖 / 写入范围 / 指派 / 完成 / 重开 / 删除），
  CAS 语义与上游一致（旧 revision → 冲突提示 + 自动刷新重取）；lead 会话推导与
  上游同规则（队友会话归其父会话的团队）；未启用上游插件时渲染「去启用」空态，
  按钮驱动真实设置入口（`button[class*="_trigger"][aria-haspopup="dialog"]` +
  打开后按文案点「插件」分区；无程序化导航 API，缺失时留在设置页）；
- 新增 `team-model.ts`（依赖无关）：草稿形状与解析、状态 → 文案键 / 色阶、变更
  结果归一化（ok / conflict / rejected）、成员可开 / 可指派判定；
- tab 注册 `id=team`（order 31，single，`teamTabIcon`：VscOrganization + 次要强调
  色）；`api.ts` 增 `teamView` / `teamCreateTask` / `teamUpdateTask`；zh/en 各 37
  个新键。

## 兼容性说明

- 依赖上游 `ctx.agentTeams`（0.1.6-alpha.2 运行时已随包）：服务缺席时走空态 +
  `service-missing`，不改变既有 tab 行为；
- **不自动挂载**上游团队服务——那套会用团队工具替换 subagent 工具，是否启用属于
  用户的选择（产品决策 2026-09-19）。
