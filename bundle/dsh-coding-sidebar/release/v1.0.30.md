# dsh-coding-sidebar 1.0.30

> 适配 dsh 0.1.7-alpha.1 契约批：图标 size-neutral 命名、V4 会话来源 kind、
> jobs kill caller 改 SessionId、依赖与 peer 范围平移。

## 变更

### 图标：size-neutral 新命名（24 文件 / 30 个导入名）

- `Icon*Outline16` / `Icon*Outline14` → `Icon*OutlineRegular`，`*Fill*` 同理
  （上游改为按字形而非字号命名）；插件自有的 19 个本地图标不动。

### V4 会话格式：来源 kind 去包装

- 消息来源废除 `kind:'plugin'` 包装——侧边对话的边界注入改用自有 kind
  `'sidechat-injection'`（按上游 time-context 同范式 `declare module
  '@deepseek-ai/dsh-llm'` 扩 `MessageSourceMap`）；**识别仍走文本前缀，行为不变**。

### jobs：kill 的 caller 类型改 SessionId

- 0.1.7 的归属栅栏按**会话**比对，继续传 Agent 会 404；结构面与注释同步。

### 依赖平移

- devDeps 12 条平移到已发布的 `0.1.7-alpha.1`（此前误判为未发布）；
- peer 11 条追加 `|| ^0.1.7-alpha.1`——**peer 范围是累加**，`^0.1.5-rc.2 ||
  ^0.1.6-alpha.1 || ^0.1.6-alpha.2` 保持不变，0.1.6 及更早宿主不被排除。

### 核对结论（无需改动）

- `agentPresets` 的 `resolve` / `mount` 保留；
- subagent descriptor 同名同参；`SubagentListEntry` 的 `activity` / `hasChildren`
  仍可用；
- `webServer` 的 `register` / `registerUpgrade` 形态未变。

## 兼容性说明

- peer 范围含 0.1.5-rc.2 / 0.1.6-alpha.1 / 0.1.6-alpha.2 / 0.1.7-alpha.1：
  0.1.6 系宿主仍可安装，会话导航等接缝自带 0.1.5 回退链；
- 本版包含 **1.0.28 的任务管理导航修复**（`workspace-nav` 接缝：等待式注入捕获
  `uiWorkspace` + 方法调用保 `this` + 三态降级）。
