# dsh-coding-sidebar 1.0.16

> 兼容性维护版（无新功能）。适配宿主 deepseek-harness 0.1.6-alpha.1。

## 修复

- **侧边栏群聊发送按钮崩溃**：上游 0.1.6-alpha.1 从
  @deepseek-ai/dsh-client-ui-primitives 删除了 IconSendOutline16
  （改名 IconPaperPlaneOutline14）。产物里是 CJS 属性访问，缺失导出变成
  undefined，渲染 sidechat 面板时 React 抛 "Element type is invalid"。
  现改为在 src/client/icons.tsx 自持该字形（与 history / save 图标同款做法），
  彻底切断对上游图标表的依赖。

## 变更

- peerDependencies 的 @deepseek-ai/* 范围由 ^0.1.5-rc.2 放宽为
  ^0.1.5-rc.2 || ^0.1.6-alpha.1。原因：npm semver 规定「带预发布号的版本
  只能被同为该 major.minor.patch 且含预发布号的 comparator 满足」，
  ^0.1.5-rc.2 实际不满足 0.1.6-alpha.1（已用 semver 实测），放宽后新旧基线同时成立。
