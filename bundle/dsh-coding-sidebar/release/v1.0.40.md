# dsh-coding-sidebar 1.0.40

> 做减法的一版：**移除「智能体团队」与「侧边对话」两个页签**（使用率低、维护面大，
> 属于鸡肋功能），同时**移除「侧边栏内容 / 文件预览」的按功能启停开关**——全部功能
> 内置开启，设置页只保留各功能的参数入口。

## 变更

### 移除「智能体团队」页签

- 页签从 `+` 菜单与注册表里整体删除；随删的还有整条支撑线：
  - 服务端：`team-routes.ts`（`team.createTask` / `team.updateTask` CAS 转发桥）、
    `team-types.ts`；
  - 客户端：`TeamView.tsx`、`team-model.ts`、`team-projection.ts` 及对应样式；
  - `context-types.ts` 的 `agentTeam` 投影镜像类型（上游 `dsh-experimental-agent-team`
    的 0.1.7 投影不再被读取）；
  - `api.ts` 的 `team.createTask` / `team.updateTask` 调用；
  - 测试：`tests/team-model.mjs`、`tests/team-projection.mjs` 与
    `run-openpath-tests.mjs` 里的对应用例块。
- 上游「智能体团队」插件本身不受影响——本插件只是不再挂它的工作台页签。

### 移除「侧边对话」页签

- 页签整体删除；随删的还有整条支撑线：
  - 服务端：`sidechat-routes.ts`（`sidechat.start/prompt/cancel/dispose/info/events`
    六条路由 + 模型跟随装订）、`sidechat-core.ts`（继承种子/边界提示/收件箱队列等纯模型）、
    `assistant-live.ts`（实时流缓冲，唯一消费方就是侧聊路由）；
  - 客户端：`SideChatView.tsx`、`sidechat-transcript.ts`、`sidechat-questions.ts`
    （提问回答路径）及对应样式；
  - `client/index.tsx` 的 `uiSession` 待答面捕获（唯一消费方是侧聊提问卡）；
  - `api.ts` 的 `sidechat*` 六个调用与 `withDeadline`（唯一用户是 `sidechat.events`）；
  - `wire.ts` 的 `sidechat-error` 错误码；
  - 测试：`tests/sidechat-*.mjs` 四件套与 `pnpm test` 里的对应条目；
  - 契约检查：`check-plugin-contract.mjs` 的 ④⑥⑦⑧ 四组侧聊回归闸随之撤销
    （⑤ CSS 类名静态比对等通用检查保留）。
- 兼容说明：历史会话里可能仍有旧版本创建的 `Side: ` 前缀子会话——
  `subagent-detect.isSideThreadSummary` 的过滤保留（常量移入该文件），
  这些行继续从子代理拓扑与活动图里排除；`wire.ts` 之外的旧持久化布局若还开着
  `sidechat` / `team` 类型页签，渲染为通用「页签类型已不可用」空态（`OrphanedTab`），
  关掉即可。

### 移除「按功能启停」开关（设置页）

- 「侧边栏内容」与「文件预览」两组小卡不再提供 enable 开关：内置页签与文件查看器
  **全部恒可用**，卡片保留为功能清单 + 设置入口（声明了 `settings.toggles` 的功能
  仍从卡片底部齿轮条进入参数弹窗，如终端字体、浏览器接管、编辑器合并模式等）。
- 随删的机制面：
  - `SidebarPrefs.tabsEnabled` / `viewersEnabled` 字段、Loader schema（volatile）与
    用户 PrefsSchema 两个入口、客户端 `parsePrefs` 解析；
  - `betterSidebar` 服务的 `isTabEnabled` / `isViewerEnabled` 方法；
  - `openTab` 的禁用拒绝分支、`matchFileViewer` 的禁用跳步、`+` 菜单的启用过滤、
    外链接管的「目标页签必须启用」前置、`openPath` 接管的编辑器启用前置、
    新会话种子在编辑器禁用时降级 `none` 的分支、`sidebar_open` 工具的
    目标页签启用预检（含 `registerOpenTool` 的 `readPrefs` 参数）。
- 旧文档里已存的 `tabsEnabled` / `viewersEnabled` 键不再被读取（缺省即全部开启），
  无需迁移。
- 偏好字段数 26 → 24（`run-openpath-tests` 的 volatile 矩阵断言同步更新）。

## 迁移与兼容

- 从 1.0.39 升级：旧的侧聊线程与团队会话**数据不受影响**（都是上游会话树里的普通
  子会话），只是本插件不再提供入口；需要继续使用这两个功能的用户请停留在 1.0.39。
- 设置文档里的 `tabsEnabled` / `viewersEnabled` 遗留键无副作用，可留可删。
