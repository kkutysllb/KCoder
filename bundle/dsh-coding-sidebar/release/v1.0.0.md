# v1.0.0（2026-09-01）

## 版本信息

- 版本：1.0.0（独立发布线首个版本，与上游版本号空间完全切割）
- 日期：2026-09-01
- Tag：`v1.0.0`
- 发布渠道：GitHub 独立仓（kkutysllb/dsh-coding-sidebar）+ npm（dsh-coding-sidebar）+ dsh-plugins 真源仓镜像

## 血缘声明

- 本包 fork 自 DSH-better-sidebar 0.17.2（上游源码面），此后作为 KCoder 维护的独立发布线：
  版本号、发布节奏、缺陷修复均不再跟随上游；上游后续版本不自动合入。
- 包名 `dsh-coding-sidebar`；server 插件名（cordis mount name）同步为 `dsh-coding-sidebar`；
  插件行 id 维持 `better-sidebar`（历史挂载位兼容）。

## 产品差异（相对上游 0.17.2）

- **移除底面板（bottom panel）**：双面板布局（主面板 + 底面板）收敛为单一侧面板 +
  自由窗口（float）+ 窄屏抽屉。底面板的组件、状态、设置项、快捷键与 CSS 已在源码级移除。
- 底面板历史持久化数据自动迁移：旧 `bottomSplits` 里的标签页在升级后落入主分割树首叶，不丢 tab。

## 稳定性修复

- **SIDEBAR_SERVICE_VERSION 单一事实源**：产物内版本常量改为构建期从 package.json version
  注入（tsdown define），终结「常量 0.17.1 vs 包名 0.17.2」式的产物/包版本脱节病根。

## 衍生插件兼容性

面向以 `dsh-better-sidebar` 为 peer 的衍生插件（office 预览 / 视频预览 / docs 面板 / 流镜 / ssh 隧道等）：

- 兼容锚点全部保留：服务点名 `betterSidebar`（`ctx.provide('betterSidebar')`，不含包名）、
  DOM 属性 `data-dsh-better-sidebar`、服务路由前缀 `/sidebar/api`、`invariant` 子导出。
- 衍生插件运行时零包名 API 依赖，唯一耦合是 npm 安装图（peer + import type）。
- 旧 peer `dsh-better-sidebar@^0.6.0` 在宿主未安装时会从 npm 拉上游真包实体，
  该实体不进 bundles 层叠、不会被加载（无双跑），仅作 peer 满足与类型来源。

## 安装与升级

- 全新安装：`dsh plugin --profile web add dsh-coding-sidebar@1.0.0`
  （或 `node scripts/install.sh` / `scripts/install.ps1` 一键安装）。
- 从 `dsh-better-sidebar`（收编线）迁移：先移除旧包再安装新包；
  旧配置键（titleBarCompat / titleBarStripPx）在宿主补写层同步改名（见 KCoder v0.5.0 发布说明）。

- 产物 `SIDEBAR_SERVICE_VERSION` 与包版本一致（1.0.0）；lib 无 bottomPanel 残留字符串。
