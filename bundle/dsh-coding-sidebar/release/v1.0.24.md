# dsh-coding-sidebar 1.0.24

> 设置页不再允许用户自行添加 Tab / 预览插件——入口与整条安装链路移除，
> 插件扩展点保留。

## 变更

- 移除设置页两张虚线入口卡「添加 Tab 插件」「添加预览插件」（`SideCardSection.tsx`
  的卡片 + 弹窗挂载 + `addPluginsOpen` 状态 + 相关导入）；
- 删除随之成为死代码的四个模块：`add-plugin-modal.tsx`（社区插件目录弹窗、
  GitHub topic 浏览、安装命令复制链路）、`plugins-tabs.ts`、`plugins-viewers.ts`
  （两个目录表）、`plugins-shared.ts`（目录条目词表）——四者构成闭包，除彼此外
  无引用，且都不在包的 exports 面（`. / ./invariant / ./client / ./client/service
  / ./client/api`）上；
- 本地化清理：zh/en 各删 11 个 `addPlugins*` 键（en 与 zh 的键集合由类型锁定，
  必须成对删），其余 19 个语言包一并清掉同名残留（209 行）；
- 样式清理：`SideCardSection.module.css` 的 `.addCard` 及其 hover / focus 变体
  （唯一使用者就是这两张卡）。

## 兼容性说明

- **能力面不动**：`ctx.betterSidebar.registerTab` / `registerFileViewer` 仍是插件
  扩展点（内置 tab 与预览器就走它），我们后续新增 tab 继续用它；
- 「侧边栏内容」「文件预览」两组清单（含各自的开关与功能设置）原样保留；
- 用户视角的变化只有一个：不再有「自己装插件」的入口（用户要求，2026-09-19）。
