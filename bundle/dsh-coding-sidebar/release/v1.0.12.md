# dsh-coding-sidebar 1.0.12

> 本版把文件 / 文件夹图标与 tab 图形交给 DSH 官方画稿，并对外新增 `registerFileIcon` 扩展点。
> （移植上游 `1d05e39` / `a4e94c9` / `22e772c` 及其两处真机返工 `fe2017a` / `da5540c`）

## 新增

- **文件 / 文件夹图标改用宿主官方画稿**：内置图形改走 `@deepseek-ai/dsh-client-ui-primitives` 的
  `FileTypeIcon`（分类交给宿主 `classifyFileType`）——48 类全彩代码 / 配置图形，外加 markdown /
  图片 / PDF / Office / 视频 / 文件夹的类目色。树行、根行、以及「编辑器 tab 带路径且非目录窗口」
  都走这条链（`src/client/file-icons.tsx`）。插件**不自带扩展名表、也没有图标懒加载分包**：整条
  图形面是平台模块里的一次函数调用，核心包 **733,858 → 745,984 字节（+11.8 kB）**。

- **对外 `registerFileIcon`（能力 `'fileIcons'`）**：按扩展名（`exts`）、精确文件名（`names`）、
  目录名（`folderNames`）注册自己的图形，优先级降序、同级按注册序，注销即回退。链序为
  **具体注册 → 注册的 catch-all → 宿主画稿**；工厂返回 `undefined` 或抛错都逐级让位（抛错记
  `console.error`），调用方永远拿到合法节点。语义提醒：宿主分类器覆盖任意路径，因此 `exts: []`
  的 catch-all 会接管**所有未被具体命中的行**。保留值 `folder` / `folder-open` 只作用于目录行，
  真实文件 `x.folder` 不受影响。

- **彩色 tab 图形**：文件 / 源代码管理 / 任务管理 / 侧边对话 / 终端 / 浏览器六个内置类型与 diff
  视图换成彩色版本（`src/client/builtins/tab-icons.tsx` + `tab-icons.module.css`），颜色**全部**
  来自 `--dsw-alias-*` 令牌（含各令牌自身的 fallback 链），模块内无颜色字面量。其中：任务图用
  **层叠图形**（该页列的是 subagent 会话 + 后台 jobs，不是待办清单）；终端图**缩一档**
  （`0.85x`，下限 10px——VSCodicon terminal 是整套里最宽的实心块），且**无描边**。

## 说明（与上游的差异）

- 上游 #429 的 563 条彩色数据表、`lib/client-file-icons.js`（255 kB）与 `fileIconTheme` 设置开关
  在本分支**从未存在**（基线 0.17.2 早于上游 0.18 的图标主题线），所以本次是「无需删除」而非
  「删除」——没有可供裁掉的体积，只有新增的调用点。
- 注册 / 回退链抽成**纯模块** `src/client/file-icon-registry.ts`（零依赖、可 node 直测，沿用
  `deliveries.ts` / `redact.ts` 的模式），`service.ts` 只做展开与 listener 复用；上游把链放在
  `service.ts` 内、靠 vitest + jsdom 覆盖。
- 上游 `22e772c` 的「原生右侧栏 tab 芯片图形」（`native/tab-adapter.tsx` + `.chipIcon`）在本分支
  **不适用**：本仓没有 `src/client/native/`（历史里也从未有），插件只注册 `settings.section` 与
  `conversation.chat.turnTail` 两个宿主槽，侧边栏整体自建宿主层（`body > div[data-dsh-better-sidebar]`）
  自绘 tab 芯片——宿主芯片那个面不存在，其效果（编辑器 tab 显示该文件图标）已在
  `Sidebar.tabIconOf` 里等价实现。
