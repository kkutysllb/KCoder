## 侧边栏 logo 容器化（brand-injector.ts v2）
- 反馈：v1 文字外加胶囊徽章"不好看"，参考图是 KStock dropdown 触发器（大圆角容器包图标+文字+chevron）。
- 改动：去掉文字徽章边框；新增 `installStyles()` 注入 `<style>`（幂等 ID `__dsh_desktop_brand_logo_style`），覆盖 `[class*="logoRow"]`（实际编译后类名 `pQ788a_logoRow`）：
  - logoRow 容器：12px 圆角、1px 边框（currentColor 22%）、4% currentColor 浅底、内边距 6/10、space-between
  - 嵌套 brand/toggle：去掉原背景与硬尺寸，配合容器布局
  - KCoder 字标（`.__dsh_brand_wordmark`）：Futura 几何无衬线 15px/600/0.8px 字距/uppercase
- 决策：vendor deepseek-harness 是纯克隆（upstream/README 明确禁止本地改动），runtime 重建不会带 patch，所以走 brand-injector CSS 注入路线；`!important` 覆盖上游 CSS Modules 几何。
- 自愈：head 中的 style 标签 MutationObserver 不会清；apply 每次检测元素不存在则重建。

## 经验沉淀
- 侧边栏品牌化元素（图标+字标）原则上不画外框，保留与 sidebar 同色透明背景，避免与图标/文字形成嵌套"框中框"视觉。
- vendor（deepseek-harness）零修改约束下的 CSS 注入模式：head 中插入 `<style>` 标签 + `!important` 覆盖，CSS Modules 类名子串匹配 `[class*="hash_xxx"]`，幂等 ID + MutationObserver 自愈。
- 校验：tsc node 侧零错误。
