## 模型输出 markdown 渲染兜底

模型偶尔会把 `**…**` 强调或 `` `…` `` 行内代码跨到下一行（CommonMark 不允许），渲染时 emphasis/code 在换行处闭合、文字结构散掉。改的位置：

- 新文件：`packages/client/ui-primitives/src/markdown/modelSanitize.ts`
  - `sanitizeModelMarkdown(text)`：
    - `**foo\nbar**` → `**foo bar**`
    - `` `foo\nbar` `` → `` `foo bar` ``
    - 围栏代码块（` ``` ` / `~~~`）内的内容不动（避免改写代码样本里的 `**`）
    - 仅修"恰好跨一个换行"的最常见情形；多行不分隔（病理情况）保持原样
- 接入位置：`packages/client/ui-primitives/src/markdown/parse.ts` — 在 `parseGfm` / `parseGfmWithMath` 喂给 `fromMarkdown` 之前跑一遍 sanitize
  - 这样 settled 渲染、streaming 增量解析、plain-text 抽取三条路径都过同一层；AST positions 都是 sanitize 之后的文本里的，相对稳定
- 新增测试：`packages/client/ui-primitives/tests/markdown-model-sanitize.client.spec.ts`（12 个用例）
- 已有 markdown 测试（`markdown.client` / `markdown-incremental` / `markdown-plain-text` / `markdown-render-units`）跑一遍全过
